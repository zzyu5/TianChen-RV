## 〇、判读法（读本册前必须知道）

1. **「被谁调用」= 机算 + 人核两步**。机算谓词（**入库、可复跑**）：
   `python3 tools/gates/gen_tools_index.py`（全量）· `--zero`（零引用者）· `--check`（本册缺行自检）。
   机算只产**候选**；「真引用 vs 散文提及」的判读由人做，结论写进本册。
   （[决策权限卡 §〇](../.trellis/spec/governance/决策权限卡.md) 来历节：**「机算」的可信度 = 那段提取代码的
   【可复核性】，不是"用了机器"这件事；即席代码是可复核性最低的形态** ⟹ 故该扫描入库为脚本，不留在 heredoc 里。）
2. **无自动调用者 ≠ 僵尸**。`.github/workflows/` 整目录已删（evidence 层 G-2），**门本体已按
   [measurement](../.trellis/spec/measurement/index.md) §3.5.2 降级为【按需工具】**——手动/板端跑。
   **按需工具无自动调用者是正当的。**
3. **退役判据 = 「它守的东西还在不在」，不是「有没有调用者」**
   （[governance · trellis卫生](../.trellis/spec/governance/trellis卫生.md) §6.3；
   「它会变空心绿」**不是**退役理由）。**拿不准 → 留 + 登记，不删。**
4. **归档件的可验地址** = `git show pre-restructure-snapshot:<原路径>`（**不是** `_attic/` 路径——
   后者 git-ignored、fresh-clone 拿不到）。死因逐条住 [`_attic/ATTIC_INDEX.md`](../_attic/ATTIC_INDEX.md)。
