## 0. 总目标 · 骨架 · 基线

**[G-0] 终极目标（v3 升级）**：建成**基于 MLIR 的能力驱动可扩展执行层软件栈之参考模板（reference template）**；**RISC-V 量化 LLM 推理为其首个高性能实例**。即：以"能力事实"为**唯一决策源**——接入一个新扩展家族 = 一个插件 + 几行表格，核心零改动；kernel 主体由机制构造（强义，见 [L-8]）而非手写；每一次变体选择可归因；每一条结构性主张机器可检验。**可扩展性是主角，性能是证明书**：模板的价值在于"照此搭法，他人可快速接入新扩展/新格式/新硬件特性"，而"该模板产出的实现能在真实硅上打赢手写出货物"是其有效性的证词。学术上支撑三条贡献（**C1（头牌）模板协议本体**；C2 模板经济学（边际成本律）；C3′ 模板产出质量（能力键控模式库））。

**[G-0b] 定位边界（防误读为扩权）**：模板 ≠ 通用编译器。"可扩展"指**栈的组织方式可复制**（schema/插件/前门/选择器/falsifier/测量宪法这套骨架），不承诺接入任意负载域；负载域主张仍锁 [G-2]。技术架构、实验协议、已有数字均不因本次定位升级而改变——**变的只有叙事、贡献排序与命名**（项目名与方言前缀改名工程 [RENAME] 单列）。

**[G-1] 双轴骨架（组织原则）**：
- **引擎轴**——机制覆盖广、主体由机制构造、可跨家族（N-operand 统一、全 zoo 构造、资源感知选择、真硬件探测、性能击败）。
- **证据轴**——每条结构性主张机器可检验（schema 冻结哈希、归因日志、模式注册表作数据、自动成本账、覆盖率进 CI、硬件探测）。
- **裁定**：成熟度指标**进 CI，不进 slides**。引擎轴让它成为成熟编译器；证据轴让成熟度可被机器证明为论文证据。两轴并列为交付，任何一轴单跑都不构成里程碑。

**[G-2] 定位红线（不变）**：执行层 / 编译后端层（Triton-backend 类比层）。负载域 = ggml/llama.cpp 型**量化** LLM 推理 kernel。覆盖率分母**永远是本负载域 kernel 清单**（[COV-1]），防止向 TVM 式端到端框架漂移。
**[G-2b] 分母卫生（反 padding 双向）**：分母**不得为凑数扩张**（[X-0] 三问），也**不得为过门收缩**。任何出域判定必须①锚 canon 条文（类型/形状族不属本负载域，如浮点类型路径、注意力算子）②入永久"域外声明名单"（附依据，可查）③**自带 anti-gate 自证**（修正后若仍未过门则如实报未过；若修正恰好帮助过门，须显式说明并接受红队复核）。分母修正报告 → 用户确认 → 才可执行。

**[G-3] 基线假设**（本纲写作时视为已成立的前提；agent 每轮先确认，任何一条失效即上报并冻结相关条款评估）：
- **[B-1]** N-operand 通用路由描述符对**产品-归约形状族**已达成端到端字节精确（含 offset-binary 三操作数与查表 N=3）；掩码/比较前缀变体**显式排除**为声明边界。
- **[B-2]** 全部块量化点积格式已经统一表驱动入口 + 能力调度 scaffold 接线（dispatch-wired）。
- **[B-3]** **双发射路径共存**：(a) 单体块量化算子 → 平面 body 发射器（描述符**选择**）；(b) 分解式 N-operand 构造路（production-e2e）。收敛目标见 [K-0]/[K-3b]。
- **[B-4]** 平面 body 参数化完成；码本参数化未启动。
- **[B-5]** 编译期选择阶段归因原料丰富（偏好分/名次/解释/并列判据/选择理由）；调度阶段（LMUL 选择）与合法性阶段的归因缺失或未核实。
- **[B-6]** 冷启动分 = 每插件常量（非能力先验，族内无区分）；向量/矩阵两家族**现**不为同一内核竞标——该前提在 P7 落地时失效（→ [SEL-2] 硬时序）。
- **[B-7]** implies 现查一层直接依赖；传递闭包修复已核**对现有判定字节中性**（现有声明全为一跳）。
- **[B-8]** 资源感知成本模型、真硬件探测两支柱未启动。

**[G-4] 快照纪律**：本纲零现值。凡数字（覆盖率、燃减、家族状态、性能）只出现在 CI 报告/内部稿，且必须携带快照 ID。

## 1. 措辞与主张宪法（写作、注释、slides 同守）

- **[L-1]（v3 扩展）** 无限定的 beat/outperform 全文禁止；性能主张必须绑定**相（prefill/decode）× 板 × 格式 × 基线 commit × 对手身份 × 八门状态 × 账本（kernel/system，[L-9]）× 双方编译器身份 × 该板 shipped-baseline 编译器**。kernel-axis vs-opponent 数字**仅在编译器对称时有效**。
- **[L-2]** "依赖式分层"只作被刻画对象，永不作发现（SubtargetFeature.Implies 在先）；术语用 **integrated（复用向量寄存器堆）/ independent-attached（独立寄存器堆）**，可引 Kulagin 2025。
- **[L-3]** 跨越用"**范式**（paradigm）"，独立性用"**家族**（family）"，不得混用；keystone 的准确表述 = "向量核上的矩阵**范式**"。
- **[L-4]** 不与 autotuning 对标；唯一允许句式：能力键控**裁剪并结构化** autotuner 要搜索的空间，互补而非替代。
- **[L-5]** 作废数据清单：06-14"输给 naive"永久作废；board-pending 期间旧性能格子不得进任何文本。
- **[L-6] 成熟度三重区分**：①"能被能力调度路由"≠"主体由机制构造"（wiring ≠ construction）；②"击败朴素/标量基线"≠"击败框架自身同 ISA 内核"（vs-naive ≠ vs-framework）；③"编译期/lit 证据"≠"硅上封存（反汇编/实测）"（export-lit ≠ silicon-sealed）。
- **[L-7] Win 登记制**：性能事件必须登记命名（Win-A：宽 LMUL vs naive 三芯片消融；Win-B：能力调优产品-归约-反量化内核，内核级，vs 真标量 + 指令级核验朴素向量，单板）。登记的 Win 只作"机制在工作"的 sanity，**绝不入 beat 语境**；任何落败/对比结论**反汇编钉死前不得书面引用**。
- **[L-8] 构造语义纪律**：论文与文档中"由机制构造 / mechanically constructed"**仅指强义 constructed**（[K-4] 定义）；弱义必须写作 "descriptor-selected composition"。弱义充强义 = 违宪。
- **[L-9] 双账本（红线；由 [CASE-COMPILER-ASYMMETRY] 确立）**：每条性能主张**必须标注账本**。**kernel 账**（源码/算法/调度质量）= 双方**同编译器、同 flags、同 march、同链接**，**禁止"我方 clang 编 vs 对手 shipped gcc 编"登记为 kernel win**（此类历史数字一律撤回）。**系统账**（产品对拼）= 允许各方使用各自的完整出货栈（我方 L3=clang .o 是设计事实；对手用其系统编译器是其现实），但**必须披露**双方编译器身份/flags/deployed object 身份/集成方式/baseline 是否 shipped-best，并**尽可能列出最强基线**（如可行：以我方编译器重编对手）。两账本互不替代：kernel 账不证"真实系统收益"，系统账不证"算法更优"。
- **[L-10] 部署身份纪律（"部署的 ≠ 证过的"）**：任何 e2e/seal 主张必须核验**实际部署物**：符号 / 反汇编形态 / vl·VLEN 形态 / forward banner / **编译器身份**（五验）。出货形态 = **clang 独立 .o 经对象导出正门链接**；**禁止**将 emitted C 注入对手构建链由其系统编译器重编后仍声称"部署了已验证 kernel"。须设"不加载我方 object 即失败"的反向控制。
- **[L-11] Amdahl 同域**：任何性能立项须先给**传导预估**（目标 kernel 相内时间占比 × 预期改善 = e2e 上限）；上限低于噪声地板者只能以机制/方法学名义立项，不得以性能名义。传导预估的输入因子必须与**目标部署同域**（同编译器、同 deployed variant、同输入路径）。
- **[L-12] 性能三层图（措辞分层）**：**L1 路径赢**（生成对手不存在的执行路径；大数字唯一来源）／**L2 调度赢**（按实例选对变体：布局/LMUL/tile/lane-width/schedule/数值档）／**L3 字节赢**（改算法结构少搬字节；常被 Amdahl 稀释，多为机制展示）。**负面清单：指令微质量（vsetvli/spill/code size）非赛场**——但此"非赛场"仅在 kernel 账内成立；系统账内**后端选择属于系统身份**（我方 clang 出货是设计事实），残留观察（如"同源码 clang vs gcc 数倍差"）限定为 pattern-specific 的生态碎片化素材，不得作为我方 kernel 质量主张。

## 2. 目标机制规格（系统该长成什么样）

### 2.1 能力 Schema（决策核）

- **[S-1] 事实模型**：每条事实含 `id`（`rvv.v` / `rvv.zvfh` / `ime.vmadot` / `scalar.zbb` / `uarch.vrgather_slow` …）、`kind ∈ {isa_ext, sub_ext, uarch, policy}`（**闭合枚举**——现状为开放字符串，收口为工作项）、`implies:[id]`、`conflicts:[id]`、`params`（**命名空间化的结构化字段**——现状为隐式字符串键，命名空间化为工作项：`vlen, elen, sew_set, lmul_budget, vreg_count, cacheline, ime.tile(...)…`）、`provenance ∈ {hwprobe, cpuinfo, vendor_table, manual}` 与 `trust ∈ {measured, declared}`（**两字段现完全缺席，新增为工作项**）。
- **[S-2] 关系语义**：加载期计算 **implies 传递闭包**（现查一层，修复与 [X-ZVFH] 同一里程碑验收，[B-7] 已核字节中性）；conflicts 命中即 fail-closed 拒绝；**未知事实 = 假**（缺省拒绝，绝不缺省放行）。
- **[S-3] 探针只写事实**：hwprobe/cpuinfo/厂商表适配器只产出事实条目；任何"探到 X 就走 Y"属违规（重新引入隐藏分支）。
- **[S-4] uarch 作为事实**：粗粒度事实（如核数）驱动决策的机制**已存在**；目标是**每核 quirk 表**（高 LMUL 下 vrgather 慢、段加载收益等，C908/X60 各一张），供 P6 键控；**走表不走 if**。
- **[S-5] schema.def 声明工件（哈希对象，[J-7] 六项清单）**：①事实记录字段与类型（含 provenance/trust 枚举）；②kind 闭合枚举；③关系类型表（implies/conflicts 及语义标注——现状关系为扁平三列表**无类型元数据**，补齐为工作项）；④params 命名空间声明；⑤插件接口签名的可序列化形态（现状为虚接口**非声明式**，反写为工作项）；⑥**路由描述符操作数角色词表**（现状**混合**：N-operand 路已结构化、块点积角色仍是表字符串——统一为工作项）。**不入 shape**：具体事实行、params 取值、插件内部代码、测量库、模式注册表条目。
- **[S-6] 两级门**：**[F-2′] 操作门（逐 PR）**——家族接入 PR 系列 diff ∩ schema.def = ∅；**报告门（逐版本）**——规范化序列化（排序 JSON）→ SHA256 + RFC 版本日志；附加式演进（新增可选字段/新 kind/新关系型）记 minor 并标注 "extension not modification"。论文主张的精确形态："自第二家族接入起，没有任何家族接入曾**要求**修改 shape"（逐 PR 可审计）。
- **[S-7] 非目标**：schema 不内置成本模型；成本住测量库（按 instance-hash 键控），schema 只答"能不能/是什么"。
- **[S-8] 家族语义（Zbb 核查的推广）**：**家族 = 能力声明 + 所有权边界，不是指令密度**。允许"**能力门家族**"——其 owned 内核主体用基础指令，家族事实充当门与可选加速子事实。子事实粒度对称成立：`zvfh` 之于向量家族 ≡ `zbb/zba/zbs` 之于标量家族。由此，广度见证家族正名为 **[X-SCALAR] 标量家族（向量缺席）**，位操作扩展为其子事实/能力门（附A 有旧标签映射）。

### 2.2 插件协议（家族接入唯一通道）

- **[P-1] 接口冻结**：`ExtensionPlugin` 为准 ABI（其可序列化签名入 schema.def ⑤）；改动需 RFC。插件可提供：事实与关系声明、合法性谓词、发射模式（向 [PAT-1] 注册）、lowering 钩子、测试；**不得**改核心目录任何文件。
- **[P-2] 接入五件套**（一个家族 = 一个 PR 系列，缺一不收）：①事实+关系表行；②合法性谓词；③发射模式（或声明复用）；④测试（lit 字节精确 + 每板 objdump golden）；⑤ ledger 条目。
- **[P-3] 接入验收 = falsifier 组全绿**（[F-1..F-6]，独立家族含 F-6）。
- **[P-4] 外部可接入（M4 定义）**：接入文档完整到"非核心作者仅凭文档可完成一次家族接入"——C1 从演示升级为协议的判据。

### 2.3 发射与构造（Track B 目标态）

- **[K-0] 双路承认与收敛**：承认 [B-3] 双发射路径；**终态 = 泛型操作数层成为唯一发射权威**（[K-3b]），平面发射器与分解构造路在其下统一；过渡期两路并存但状态按 [K-4] 六态如实标注。
- **[K-1] Emission Plan 为中心工件**：声明式配方 = 迭代结构 + body 模式引用 + 能力键；可序列化、可 lit。
- **[K-2] Body 模式库**：加宽–点乘–归约、dequant 查表/位解包、repack/blocking、归约树、掩码尾部处理、**[K-2b] 宽钳位/双区 body（widen–clamp–narrow，首个"缺口关闭"模式，关闭后同内核同板复测 vs 自动向量化）**；每模式以 (SEW, LMUL, VLEN 符号量) 参数化；**码本参数化**为专项（现未启动）。
- **[K-3]（基线，带边界）**：N-operand 达成于产品-归约形状族；掩码族排除入边界地图。**[K-3b]（M2）**：泛型操作数层成为唯一发射权威；验收 = 既有三形状 + 掩码族之一经泛型层重发射，字节精确不回退。
- **[K-4] 六态阶梯（全分母内核统一状态机，可自动读出）**：
  `absent → emittable（可发射+转换级单测） → dispatch-wired（生产调度接线，body 手写） → constructed-weak（描述符参数化组装，算术主体为被选择的手写 helper） → constructed（body 由模式库原语构造，强义） → covered（constructed + [K-5] 时效适用项全绿 + 回归架记录在案）`。
  硅封状态（每板 objdump golden）**单列跟踪**，不并入六态。**单体 body 燃减清单**（K-quant / 码本 / fp4 / 三值等）由状态机自动生成，进 CI 报告。
- **[K-5] 正确性门**：整数路径字节精确；浮点路径 ULP 上界声明；VLEN 翻转 lit 矩阵 ≥ {128,256}×{m1,m2,m4}；每板 objdump golden（指令形态 + LMUL 断言）；全部进 CI。
- **[K-5b] 证书三要件（进 CI；由 [CASE-MINTERM] 三次反转确立）**：任何正确性证书必须同时满足——①**语料完备**（每个算术项被非退化 exercise：如 dmin≠0、满幅 scale、交替符号、次正规；仅测退化语料 = 该项从未通电）；②**输入路径同源**（oracle 与被测 dispatch 逐环同源；cert 必须声明其输入路径谱系——用 row-quant oracle 去验 mat-quant dispatch 是致命坑）；③**oracle 独立**（不与被测物共享读取/解码实现——"空心证书"禁令：共享实现会让同错互相抵消）。旧 cert 按三要件补标注，缺项降级 partial。
- **[K-5c] ZERO-MODEL 终审法**：正确性争议不靠"kernel vs 某 oracle"多轮互搏（oracle 本身可能选错）；终审 = **捕获真实 dispatch 输入 → 用被测系统自身原语从该输入重算 → 与 kernel 中间值逐位对**。争议默认走 ZERO-MODEL → 独立实现对位终审两步。**单证书永不定案；定罪与翻案同等严谨。**
- **[K-6] 缺口关闭环 [GAP-1]**：任何性能落败（或意外持平）必须归档 triage 为四选一——`{缺能力事实 | 缺模式 | 选择错误 | 物理（带宽墙）}`；追因需反汇编/计数器证据（[L-7]）；判为缺事实/缺模式者 → 命名新条目进 schema/注册表 → 关闭 → 同内核同板复测 → 归因日志引用缺口 ID。此环的档案本身是 C3′ 的叙事素材（负例 → 可归因修复）。**新增 triage 类别（实战补充）：`{未接线（emitted kernel 未被推理框架 forward 消费）| 部署身份错误 | 编译器不对称}`——前者是 e2e 稀释的头号原因，不得与"物理"混判。**
- **[K-7] 首次发射律 [LAW-FIRST-EMISSION]（C3′ 核心实证，已四例连档）**：**首次发射的 kernel 功能正确但性能不成熟是常态；其成熟杠杆可具名、可由能力事实键控、可族级复制。**已证四例：输出瓦片化（register-cliff 类）、循环序交换（冷流式内存墙）、满宽 lane-width（VLEN 事实未流入发射器）、叶批处理（逐指令仪式开销）。推论：性能覆盖面（perf-covered）可**按批**提升而非逐格硬凿——因每把杠杆都是族级/范式级。
- **[K-8] 发射权威机检 [F-EMIT]（进 CI）**：生产 dispatch 路径上的每个构造格必须携带 front-door provenance；**检测到绕过 L2 typed-region 的直连发射路径被生产选择器选中 = 红**。过渡期旁路格白名单化（带退役批次号），**白名单只减不增**。终态 = 旁路清零（[K-3b] 唯一发射权威的机器保证）。
- **[K-9] 退役可复原闸**：任何 kernel/发射路径的退役必须 ①git 历史可查 ②登记四要件（格名 / 退役依据 / 替代路径 / 复原指针）；登记形式可为结构化 ledger 或 canon 指定的 `.td` RETIRED NOTE（四要件齐即合格）。CI 校验"一切已退役格 ⊆ 自动生成的 RETIRED-INDEX 且四要件非空"——无登记的删除 = 违规。

### 2.4 合法性 · 调度 · 归因（fail-closed 双门 + 三级归因）

- **[D-1] 编译期门**：plan 合法 ⇔ 能力谓词在目标 schema 实例（含闭包）下全部可满足；任何未知 ⇒ 拒绝；**该拒绝必须自足**（不依赖调用方兜底）。
- **[D-2a] 装载期最小解析（M1，重构现有）**：现有"编译期物化、调用方一次性提供的能力开关"重构为：消费显式 schema 事实实例 → 计算 **declared-instance-hash** → 落一条解析记录。热路径零逐次检查；**per-dispatch 强制永久禁止**（[NG-3]）。
- **[D-2b] 完整运行期链（M2/M3，增量）**：hwprobe 适配器 → 事实（provenance=hwprobe, trust=measured）→ instance-hash → **[D-3] 调度表按 instance-hash 键控**（同一二进制多板装载不同变体集，核心不变）。
- **[D-4] 三级归因**：
  ① **编译期选择归因（M1 硬门 = 100%）**：JSONL `{kernel, candidates[], keys_evaluated{}, chosen, reason∈{only_feasible, prior, measured}, declared_instance_hash, ts}`——由 [B-5] 富属性重构出口；
  ② **装载期解析记录（M1 硬门 = 每进程 1 条）**；
  ③ **运行期归因（M2+，随 D-2b）**。
  **归因范围扩展（M2 增量）**：调度阶段（为何选此 LMUL）与合法性阶段（为何拒）纳入日志——[B-5] 指出这两段现缺。

### 2.5 选择器（Gearbox 目标态）

- **[SEL-1] 两段式**：`feasible = 合法性过滤(candidates, schema)` →（有测量）memoized argmin →（冷启动）**能力先验排序层**：GEMM 形状 ∧ `ime.present` → 矩阵范式变体；否则寄存器预算内最宽 LMUL；否则默认。先验层独立于成本函数，**不污染成本纯度**。
- **[SEL-2] 硬时序**：先验层必须**先于或同于 P7（矩阵接管 GEMM 形 prefill）落地**——[B-6] 的"两族不竞标"在那一刻失效，先验层从装饰变裁决者。
- **[SEL-3] 测量回填与声明限制**：异步微测 → 测量库（instance-hash + kernel + variant 键控）→ 命中 memoized 路径。无搜索、无成本模型学习；留外部 tuner 插点（文档化即可）。

### 2.6 Falsifier 组（C1 证据标准，全部进 CI）

- **[F-1] 零分支**：`grep -rE <family_regex_manifest> core/` 命中 = 0（白名单仅表格文件）；每家族接入登记其名字/助记符正则；需一个能区分真分支与同名假阳性的判读规程（命中即红，白名单变更走 RFC）。

- **[F-4] 归因完备**：按 [D-4] 分级——M1 查①②，M2+ 查③。
- **[F-5] fail-closed 模糊测试**：随机删除/伪造事实实例下，非法 plan 全部被拒（非误编译/误发射）；向量缺席实例复用为 [F-6]/[X-SCALAR] 测试资产。
- **[F-6] 独立性判据**：声称 independent 的家族，其全部变体能力谓词 implies 闭包 ∩ {rvv.*} = ∅（脚本化）；且存在向量缺席实例使其变体 `only_feasible` 并被真实选中。

## 3. 覆盖率与成熟度（"真正的 compiler"怎么量化）

- **[COV-1] 覆盖分母（agent 钉死 ggml commit 后定稿清单并提交回仓库）**：
  *A 类（关键路径）*：**全部块量化 `vec_dot` 格式（含平面 4/5/8-bit、K-quant 超块、码本/低比特查表、fp4、三值——低比特族按裁决从"暂缓"移入分子）**；`quantize_row`/`dequantize_row` 相应格式；分解产品-归约家族；prefill GEMM tile（RVV 全格式 + IME×{q4_0,q8_0,q4_K} 起步）。

  *C 类（显式暂缓防漂移）*：flash-attn tile、bf16 全套、其余显式列出。
- **[COV-2] 指标集（v3 修订）**：
  `C_dispatch` = ≥dispatch-wired / 分母——**降为附注指标，不作成熟度 headline**（"能被路由"≠"由机制构造"）；

- **[COV-3b] 性能轴目标态（与 COV-3 并列）**：性能"立住"的定义 = **覆盖面而非孤点**——T3 表成片绿 + 每个非绿格具名归因，出口四选一 `{未接线 | 传导稀释（附 Amdahl 账）| 物理 parity-at-floor | 声明例外}`，**零含糊格**。单个 sealed Win 是必要不充分条件。

- **[COV-5] 性能回归架**：每 kernel 微基准 + llama-bench 端到端，prefill/decode 分相，固定频率、钉核、中位数+方差，对同 commit 上游 ggml，按 instance-hash 存库，进 CI。

## 4. 三条贡献的终态规格

> **v3 重排**：**C1 升为头牌**（它就是"模板"的本体：协议本身）；**C2 = 模板经济学**（照此模板接入新扩展有多便宜——模板价值的经济学证明）；**C3′ = 模板产出质量**（模板产出的实现好不好、性能数字是其证词）。三者共同回答："这个可扩展软件栈模板，是什么（C1）、值多少（C2）、产出如何（C3′）"。
>
> **[L-13] "家族"三分法（术语红线，全文强制；曾因语义漂移致 C2 记错账）**：
> **extension family**（RVV / IME / scalar / …：独立或 integrated 的**指令集扩展家族**）——**C2 的唯一成本对象**；
> **kernel family**（同一算子的一组实现）；
> **decode family**（q4_K / codebook / ternary 等**量化格式族**）——其前门化/接纳成本属 **C3′**（construction pattern 与工程成熟度），**绝不计入 C2 曲线**。

### 4.1 C1（头牌）—— 合取机制的存在性 → **可复制的扩展接入协议（模板本体）**

- **[C1-1] 主张（终态）**：一份带关系的能力 schema 同时驱动编译期变体生成与 fail-closed 运行期（装载期解析形态起步）调度守卫，**跨计算范式边界（向量 SIMD → 整矩阵 MAC）且跨独立家族（向量缺席的标量家族）**原封复用；零家族分支由 [F-1..F-6] 机检；接入由外部贡献者按文档可复制。
- **[C1-2] 机制依托**：S 全组 + P 全组 + D 全组 + F 全组。
- **[C1-3] 证据阶梯**：家族 #1 RVV、#2 IME（跨范式，已有）→ #3 [X-SCALAR]（广度半边）→（条件）#4 AME（矩阵半边，论文不押注）。
- **[C1-RW] 相关工作六对照面（成文必备，缺一面"artifact, not idea"即可捅入）**：A 逐平台手写（Cambrian：每平台专属 micro-kernel+packing）；B 逐目标生成（ACT/TAIDL：N 个后端 vs 我们 1 后端+N 插件）；C 多路径框架（CONVOLVE/DATE'26：每类目标一条专属路）；D 硬件侧统一（CUTEv2：改硬件不改软件抽象）；E 运行期分发现状（FMV/IFUNC/hwprobe：单家族、仅运行期、同范式）；F 表示层统一（heteroMx/Kulagin 2025：统一 IR 表示、推迟 lowering、无运行期无零分支——我们统一决策层，恰补其所缺）。
- **[C1-4] 验收**：falsifier 组 ≥3 家族下 CI 常绿；schema.def 自 IME 起未被家族接入触及（F-2′ 逐 PR 审计）；六对照面成文；（M4）外部接入实录。
- **[C1-5] agent 检查**：falsifier 脚本在且可跑？schema.def 与版本日志在库？regex manifest 齐？接入文档可独立走通（干跑评估）？

### 4.2 C2 —— **模板经济学**：依赖式分层接纳 + 泛化代价（→ 边际成本律）

- **[C2-1] 主张（终态，v3 改写）**：零分支/零核心改动不变量下，逐 **extension family**（[L-13]）接入代价服从可解释的成本律：
  **① integrated 子扩展廉价**（复用宿主家族的 emitter/模式，成本≈事实行+谓词+测试，如 zvfh 级）；
  **② independent 家族必须支付真实 emitter 成本**（[F-6] 独立性判据禁止复用宿主 emitter，故存在成本地板）；
  **③ 成本不单调递减**——递减发生在"同宿主内的子扩展"维度，不发生在"新独立家族"维度；**复用边界由独立性要求决定**。
  并给出结构解释（成本住模式/谓词/测试/胶水哪一处）。
  > **v3 撤销**：v2 的"标量家族 <300 行"目标作废——该数字隐含"可复用 RVV emitter"的假设，与 [F-6] 独立性判据冲突；实测独立家族成本远高于此。**成本更高不是失败，而是把成本律修正得更真**。
- **[C2-2] 机制依托**：LED 全组；术语按 [L-2]/[L-13]。
- **[C2-3] 验收**：ledger 自动生成且首点可复算；**≥3 个 extension-family 级数据点方可称"曲线/规律"**（不足则必须诚实标注"曲线缺失(n/≥3)"）；[LED-3] 两锚在位。
- **[C2-4] 归属纪律（[LED-4]，v3 新增红线）**：**decode-format 前门化的 LOC/工时一律不得记入 C2**（它们是 C3′ 的 construction-pattern 成熟度数据）。C2 表只接受 extension-family 行。历史误挂须逐条正名（数值保留、只改归属）。锚点变更（如首家族 LOC 口径调整）必须带**新旧口径对照 + 日期**，禁止静默换锚。
- **[C2-5] 审稿人预答**：①"第三家族太小" → 子扩展成本低**正是主张①**；②"为什么独立家族没有更便宜" → **主张②即答案**：独立性是我们自己立的机检判据（[F-6]），付出的 emitter 成本正是"独立"的价格，此为诚实而非缺陷。

### 4.3 C3′ —— **模板产出质量**：能力键控优化模式库（→ 带实测、迁移与边界的模板）

- **[C3-1] 主张（终态）**：P1–P8（含 P2b）以能力谓词表达、由机制选出（归因日志）、跨 VLEN/微结构**换键不改条目**地迁移（[PAT-3] CI 常绿），对 tuned ggml **分相**报告增量；模式库覆盖 C_construct ≥70%（强义）的 kernel 体。**v3 扩展：模式的适用性本身是可预测的**——见 [C3-1b]。
- **[C3-1b] 迁移可预测性 [XFER-1]/[PAT-S6]（v3 新增，C3′ 最强证据形态）**：优化能否迁移**不由格式名/家族名决定，而由瓶颈形状决定**。已机检的三分类：**① register-cliff**（压力来自可 staging 的 decode strip / 闲置累加器 → 输出瓦片化 HOLDS）；**② weight-reconstruction-bound**（压力来自不可 staging 的多平面权重重建 → NULL）；**③ already-lean / gather-bound**（已在寄存器悬崖以下，无可释放压力 → 结构性 no-op）。判据统一为一句可证伪的谓词，并以**事前预测 → 板上验证**的形式逐格记账（预测-实测对照表进 T3p）。**正例、负例、边界齐备**是本贡献区别于"一堆优化技巧"的关键。
- **[C3-1c] 方法学卷宗（负例与自纠，v3 新增为一等证据）**：C3′ 包含三类经实战确立的案例档案：**①正确性误诊与自纠**（证书盲区 → ZERO-MODEL 终审 → 三要件入宪）；**②测量效度清算**（编译器不对称 → 双账本入宪，含历史数字的公开撤回）；**③micro↛e2e 机理**（热 micro 掩盖冷流代价 → 计数器归因 → 单变量修复 → 翻正）。**"能抓住自己的错误并把纪律机器化"本身是模板可信度的元证据。**
- **[C3-2] 机制依托**：PAT + K（含 [K-7] 首次发射律）+ SEL + COV-4/5 + GAP-1。
- **[C3-3] 证据阶梯**：① H3 = h16 机制归因（随 [D-4]① 顺手落，最便宜）；② H2 = P1 对 tuned 的增量；③ [K-2b] 钳位回归关闭并复测（把落败翻成"缺口被命名→被关闭→可归因"）；④ P7 或 P4 的 prefill 赢；⑤ 双板迁移判据常绿。
- **[C3-4] 诚实边界**：decode 大概率带宽墙 → 主张锁 prefill；[L-4] 红线；弱义构造不得计入模式库覆盖（[L-8]）。
- **[C3-5] agent 检查**：注册表是数据文件而非散文？P1/P2 条目与现有 pass 一一对应？归因日志 schema 已实现？测量库主键 = instance-hash？

### 4.4 性能验收门 [PERF-1]（beat 的唯一放行通道；v3 加固）

① 字节精确（或声明 ULP 界）；② VLEN 翻转 lit（128/256 双配置）；③ **双板各一次 objdump 验封**；④ micro **且** e2e（llama-bench，prefill/decode 分相，多 prompt 长度）；⑤ 双板都验证；⑥ 实验纪律（**噪声自检**（[PERF-2]）、钉核、中位数+CI、同 commit 上游 ggml、报模型/量化格式/上下文长度）；⑦ **机制合成归因**（selector 日志证明获胜变体由能力键选出）；⑧ 措辞门（主张精确到相，[L-1]）。
**v3 增补两项前置（不满足则整门不予受理）**：⑨ **账本合规**（[L-9]：kernel 账须编译器对称；系统账须完整披露且尽力列最强基线）；⑩ **部署身份五验**（[L-10]：符号/反汇编/vl 形态/banner/编译器身份 + 反向控制）。
八项（十项）全绿前，任何"击败"不存在。**跨板 Win 的正确形态**：若两板由**不同杠杆**各自取胜（如一板 lane-width、一板 schedule），登记为"**方法跨板泛化**"而非"同一 kernel 双板复制"，且须披露各板对手身份差异（是否为该板 as-shipped 出货物）。

### 4.5 [PERF-2] 测量纪律（共享板现实；替代 loadavg 硬闸）

**噪声自检**：测前跑 3 次重测-重测 sanity（同 kernel 同配置），运行间 IQR ≤ 该基准类历史噪声地板 ×1.5 → 板可用，**立即开测，不看 loadavg**；loadavg 与邻居进程快照**降级为记录项**（入环境指纹，供审计"当时板上有谁"）；测中 IQR 突劣 ≥3× 自检值 → 该会话作废重跑。**0 样本永不造数**（红线：宁可无数，不可编数）。非计时测量（objdump 计数、字节比对）无窗口约束。

## 8. 治理与文档族

- **[GOV-1] 单一权威**：本纲 = 规范源；现状与数字住 CI 报告 + 内部核查稿（file:line 锚点）；写作口径与诚实边界住研究档。三者共享同一套快照。
- **[GOV-2] 任务口径统一**：任务状态必须从子项自动聚合或按固定节拍人工核对——"母任务待审核、子任务已完成"类张力应被脚本消灭。
- **[GOV-3] 快照纪律**：agent 与 CI 的一切数字携带快照 ID；跨快照比较必须显式声明区间。
- **[GOV-4] ROADMAP 工件化（治长战役中的全局感知丢失）**：常驻 `ROADMAP.md`（北极星 / 当前坐标 / 在飞 / 排队顺序即优先级 / 对账清单 / 测量欠账表）。**每份阶段简报第一节必须是 ROADMAP 快照**（坐标 + 在飞 + 队首 + **并行度 N 及各线域**），缺此节 = 简报不合格。坐标数字随事实更新；**排队顺序仅由用户裁决变更**。禁止上下文压缩后"重新发明项目世界"。
- **[GOV-5] 决策权限卡（治 agent 频繁回门）**：
  **自决直行**（做完日志记一行）：已立项战役内的里程碑推进与排序；队列内执行细节/测量/入表/triage；**预注册判读的执行含其全部后续动作**（判据满足 → 直接登记/升格/翻正/降级/进下一里程碑，**不回门**）；**措辞预注册制**（凡预注册判读涉及登记/升格，必须同时预注册措辞模板留数字空位，落地填数即用——措辞不再构成回门理由）；公开资源获取（复现/测量所需的公开模型与数据：自行下载+校验+登记）；可逆工程决策；已立项两线间的资源微调（以触碰集 diff 为证）。
  **必问**：**ROADMAP 队列外的全新战役**（既定裁决的**合并 / 分批 / 里程碑推进不算新战役**）；canon/红线级变更（改定义/改红线/改既有条文——**按预注册模板填数登记不算 canon 级**）；不可逆动作；停机规则触发且无预案；花钱/许可证存疑/板硬件之外的外部世界动作。
  **灰区**：不确定 → 选可逆路径先行 + 标记决策点 + 继续，**不 idle 等待**。
  **禁止**：把自决事项包装成选择题或"必问"回门（= 转嫁决策）。
- **[GOV-6] 禁停机制**："会话已长 / 完成了一个里程碑 / 上下文将压缩 / 用户未回复 / 想等用户审视"——**永不构成暂停或回门理由**。里程碑的正确动作 = 报备一行 + 读 ROADMAP + 续队首。队列（= 测量欠账表 + 排队项）**永远非空**；若真为空，正确动作是列出剩余项请求排序，而非提议暂停。
- **[GOV-7] 并行默认与工程债定位**：能并行的一律并行（每轮先做**触碰集 diff**，不相交即同跑；单线运行须附串行理由）。**工程债 = 与主线并行的卫生工作**；凡提议"X 完成后才回主线"，必须附"X 如何具体阻塞主线"的证据，否则默认并行。
- **[GOV-8] 代码事实优先于计划文档**：排期与立项前必须做代码事实核查；计划文档陈旧不作为依据（已有多起"以为要从零建、实为已完成大半"的 stale 排期）。
- **[GOV-9] 命名冻结**：不得为既有概念自造新名（历史上多起同物异名致 agent 混乱）；新概念先提案入 canon 再使用；同名异义（工具名 vs canon 概念）须在索引中显式消歧。

## 9. Agent 差距核查协议 v2

- **[A-1] 输入**：本纲 + 仓库 HEAD（钉快照 ID）+ 内部核查稿 + dossier 冻结点。
- **[A-2] 第一步 = 基线确认**：逐条核 [B-1..B-8]；任何失效置顶上报并冻结受影响条款的评估。
- **[A-3] 输出格式**：每条款一行 `{条款ID, 现状(1-3 句 + 内部稿锚点), 等级: 满足|部分|缺失|越界, 建议动作, 关联}`；末尾三张汇总表（按贡献 / 按等级 / TOP-10 优先动作）。

- **[A-5] 计算规约**：LOC 用 cloc、测试单列；分母清单文件提交回仓库；C_construct 只计强义，弱义单列为 C_construct+。
- **[A-6] 禁止**：不得为满足条款弱化不变量（家族名移入字符串常量躲 grep = F-1 精神违规）；**不得把弱义构造报为强义**（[L-8] 违宪）；不得引用未钉快照的数字。
- **[A-7] 时效项清单**（每轮必须重测）：四覆盖率现值、燃减清单、六态表、Win 登记簿、[K-2b] 钳位回归状态、[X-ZVFH]/[X-SCALAR] 接入进度、硅片核查状态。
