## 0. 一句话

今天 tiling 不是一个显式变量，而是"调哪个 body-emitter"的副产品，且**调哪个由 `decode_model`（per-format）定死**。SEL-1 把它提升为【运行时能力键控选择】：变体注册 → 合法性过滤 →（有测量）memoized argmin →（冷启动）[XFER-1] 能力先验。选型键 = **瓶颈形状 fold_model（结构/能力事实），不是 format 名**。

## 2. 一页设计

### ① 变体注册表（编译期硬编码 → 运行时选择）

- **有界枚举**（NG-1）：`RVVRepackTilingVariant { Plain, S6Tiled }`。
- **body-emitter 参数化 tiling**：把现在分居 `emitRepackKQuantGemmBody{Q4K…}`(tiled) 与 `{Q6K,Q3K}`(plain) 的两套 body 收进"一个 emitter + 两个模式旗"，**byte-exact 保 both 现状**（tiled/plain 代码均已存在，只是搬进旗控）。
- **注册项** = `{ kernel-id(decode_model), variant∈{Plain,S6Tiled}, legality-pred, cold-start-prior-class }`。
- **谁选/谁读的翻转**：选不再是"which emitter"，而是**选择 pass 计算 variant → stamp 成 loop-body op 属性**（`tcrv_rvv.tiling_variant` + reason）；emitter 退化为**纯 realize**（读属性发对应模式，**缺省=现状**→向后兼容）。GEVM 叶只注册 `Plain`（单变体）。

### ② 测量库 schema（offline profile cache）

- **主键** `(declared_instance_hash, kernel, variant)` → timing。`declared_instance_hash` = `computeDeclaredInstanceHash(展开规范化能力事实集)`（`DeclaredInstanceHash.h`，**已存在**，与 [D-4]①/[D-2a] **同一 hash**）。`kernel`=decode_model；`variant`∈{Plain,S6Tiled}。
- **value** = `{ measured_ns | vs_generic_ratio, board_identity(vlen/vreg/march), byte_exact_gate: pass, samples/cv, ts }`。
- **住哪**：版本化 JSON `schema/tiling-measurements.v1.json`（或 experiments cache）；**不入 `lib/`**（schema 不内置成本模型；实测是缓存事实非 authority，I4 + 权威顺序）。
- **怎么填**：offline-profile 谐调器 **on `ssh rvv`**（spec Autotuning「Offline profile」档）：对每 `(instance,kernel,variant)` 构造→编译→跑 micro/llama-bench→**过 byte-exact gate**→回填赢家。
- **怎么查**：选择 pass 冷启动前先查 `(instance_hash,kernel)` 下有无两 variant 实测；有→memoized argmin（min ns），`reason=measured`；无→落先验。**fail-closed-revalidate**：记录里 variant 若已不 feasible → 丢弃，退回先验。

### ③ 归因日志 schema（[D-4]①）

复用 `buildSelectionAttributionRecord`（`VariantSelection.cpp:1048`）的 JSONL 形态，每条：
`{kernel, candidates[]{variant,score,feasible}, keys_evaluated{vlen,vreg_count,…}, chosen, reason, declared_instance_hash, ts}`。
- **reason 是主键**（spec [D-4]：键控做在主键、不做脚注守卫），`reason ∈ {only_feasible, prior, measured, static_order}`：
  - `only_feasible` = 过滤后仅 1 变体（GEVM 叶恒此；GEMM 在 VLEN256/vreg 预算只容 plain 时亦此）。
  - `measured` = 命中测量库② argmin。
  - **`prior`** = [XFER-1] 能力先验裁决（见④）— **严格保留能力派生**，今天 stage① 绝不发（SEL-1 落地才出现）。
  - `static_order` = 能力盲兜底 → **不应出现**；出现=先验覆盖缺口（燃减信号，spec [D-4] 不变量）。
- **落盘**：与 exec-level 归因同 JSONL sink；GEMM loop-body 上另挂 inert attr `tcrv_rvv.tiling_selection_reason` 供 lit CHECK。gate ⑦ 认证 = 每 K-quant 格 reason ∈ {prior,measured,only_feasible}、**非 static_order/hardcode**。

### ④ canon 两段式 SEL-1 + [XFER-1] 冷启动先验

**Stage 1 合法性过滤**：`feasible = { v : peak_vreg(v, vlen, vreg_count) ≤ vreg_count }`（用 §L1-tiling-schemes 的 `peak(mr,hs)` 公式；VLEN256 下 h 轴消失、hs 强制=1）。`feasible=∅` ⇒ **fail-closed 诊断**（I7），不合成 route。

**Stage 2 排序**：
- **有测量** → memoized argmin（测量库②），`reason=measured`。
- **冷启动（无测量）** → **[XFER-1] 3-类能力先验**（cost-model-free 规则式裁决，**不污染成本纯度**；效仿既有 `chooseFillOptimalLMUL`/`RVVFillLMULReason{Prior,…}` 的 prior 范式，`RVVGearboxSchedule.h:2689`）：

  | 瓶颈形状（键=`fold_model`，非 format 名） | 格 | 先验变体 | 依据（§二.4 实测 4/4 命中硅） |
  |---|---|---|---|
  | **min-fold register-cliff**（`kquant_dmin_bsums_min`） | q4_K/q2_K/q5_K | **S6Tiled** | register-cliff lever 键控 min-fold，spill→v30，HOLDS |
  | **dual-plane weight-bound**（`kquant_single_scale_no_min`） | q6_K/q3_K | **Plain** | 峰值=权重重构，tiling NULL |
  | **already-lean**（codebook） | iq4_nl/iq4_xs | **Plain** | 已 ≤32-vreg cliff，tiling 结构 no-op |

  `reason=prior`。键 = **瓶颈形状（能力/结构事实）而非 format 名** → 满足 C3′「换键不改条目」迁移判据，且**从机制上防 format-name 分派复发**。
- **静态 `peak(mr,hs)` 公式仅作 (1) Stage-1 剪枝 + (2) 先验后兜底默认，非冷启动排序 authority**（spec [SEL-1] 成本纯度）。

**NG-1 红线守卫**：变体集=有界枚举 `{Plain,S6Tiled}`；精化=**实测记忆**（offline profile，非在线学习）；先验=**3 类硬映射规则**（非搜索、非 curve-fit cost model）。**无 autotune 搜索、无学习成本模型。**
