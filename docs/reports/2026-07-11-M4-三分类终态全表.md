## 4. 机检核验（脚本对账 = 93、零未定义格）

```
$ python3 .trellis/scripts/coverage_metrics.py report | jq .m4_classification
{
  "certified": 81, "blocked_on_IME": 3, "declared_exception": 7,
  "out_of_domain": 2, "denominator": 91, "roster_total": 93,
  "undefined_cells": [], "reconciliation_ok": true
}
```

`reconciliation_ok` 断言：`certified + blocked-on-IME + declared-exception == denominator (91)` **且** `denominator + out_of_domain == roster_total (93)` **且** `undefined_cells == []`。任一 in-denominator 非-certified 格若缺 `m4_class` 标记 → 落 `undefined_cells` → `reconciliation_ok = False`（self-test `un-marked non-certified cell surfaces as undefined` 用例守此）。

**结论**：93 全量对账闭合，**零个未定义格**。
