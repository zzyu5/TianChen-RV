## 一. ★ 口径：「描述符 LOC」到底数的是什么

> 本役前科 2 = **文件数当行数**；前科 1 = 散文裸数三方重建三个值。
> 所以：**先把数的是什么写死，再数**。凡下文数字，全部由
> `tools/visibility/e6_descriptor_cost.py` 自 emit，**本报告零散文裸数**。

### 1.1 ★★「描述符」在本仓是**过载词**（本役最大口径陷阱）

至少 **4 个不同的东西**都叫「描述符」：

| # | 名字 | 形态 | 本役是否量 |
|---|---|---|---|
| **(1)** | `k<Fmt>DecodeFacts` 前门解码事实记录 | **声明式** `constexpr` 记录 | **✔ D1 量的就是它** |
| **(2)** | `FlatBlockDotDescriptor`（`deriveFlatBlockDotDescriptor` 的 per-`kind` arm·C8 报告「平面描述符 **7 kind**」） | **命令式** switch arm 代码 | 单独 emit·**不入 T2** |
| (3) | N-operand 通用路由描述符（总纲 v3 `[B-1]`） | — | ✘ 未量 |
| (4) | 调度描述符（LMUL 旋钮） | — | ✘ 未量 |

**(1) 与 (2) 不是同一个量**：一个是声明式记录的行数，一个是命令式分支的行数。
**禁相加·禁平均·禁同轴作图**。二者混进同一列 = 前科 2 的新变种。

### 1.2 D1（**主口径·落 T2 的就是这个数**）

```
D1_raw_LOC = 从 `constexpr <Family> k<Fmt>DecodeFacts = {` 行
             到其配对 `};` 行，【含首尾】的 raw 物理行数（wc -l 语义）
             @ pin HEAD·由花括号配对机器抽取·禁手数
```

- **边界文件**：`lib/Plugin/RVV/FrontDoor/RVVLowerQuantContraction.cpp`
  （已机核：`DecodeFacts` 在 `lib/`+`include/` 内**仅此一个文件**有定义点）。
- **`D1_code_LOC`**：额外剔除空行 + **纯注释行**。
  之所以并列 emit：本项目有 **P5「数标注不是数算术」**前科。
  **实测 15 个描述符 `D1_raw == D1_code` 全等** —— 因为字段是 `/*name=*/value,` 的
  **行内**设计符，不存在纯注释行。即本口径**未重犯 P5**（这是 emit 出来的结论，不是我说的）。

### 1.3 并列 emit、但**不入 T2** 的量

| 量 | 是什么 | 为何不入 T2 |
|---|---|---|
| `D2_raw_LOC` | D1 + 紧邻其上的连续 `//` 文档注释块 | 真实撰写成本，但注释长度是**行文风格**产物、非结构成本。**摆出来供查，不藏** |
| `shared_*_LOC` | `struct <Family>DecodeFacts { ... }` 定义 | **per-family 共享基础设施**，被家族内各格式摊薄。**除以格式数 = 造数** ⟹ 整块报、**永不切分** |

### 1.4 ★ 明确**排除**项（点名·非默默丢弃）

verifier 谓词 · emitter core brick · repack oracle · registry dispatch arm。
理由：**(a)** 无我方敢辩护的 per-format 机械切分规则；
**(b)** emitter/brick 构造成本**已由 T2 既有列 `ledger_delta_hand_LOC` 承载** ——
在此再数一遍 = **对同一列双重计数**。

### 1.5 ★★ 存量 vs 流量（**最要命的口径分界**）

| 列 | 语义 | 测点 |
|---|---|---|
| `ledger_delta_hand_LOC`（既有） | **流量 FLOW** = flip commit 处的**增量** | at flip |
| `descriptor_LOC`（本役新增） | **存量 STOCK** = 描述符在 pin HEAD 的**当前大小** | at HEAD |

**二者不同量纲 ⟹ 禁相加·禁作差·禁同轴。**
要在 flip commit 处测描述符 = 需 `--at-commit` 复现能力 = **对照表 B9**
（PR-22 已登记·**无承接**）⟹ **本线不做 B9**（越界禁令）。

## 三. ★★ 红线自证：这些数**没有**进 C2

### 3.1 不冲突论证（v4 草案 §5 立场·**本线不推翻 [C2-4]**）

`[C2-4]/[LED-4]` 禁的是「**记入 C2**」（= 贡献主张 / 成本律 / 曲线的**归属**）；
订正注要求的是「**记入 T2 作披露**」（= 表内一列·分层标注）。
⟹ **披露 ≠ 归属**。本役**未动 [C2-4] 原条文一个字**。

### 3.2 分层隔离怎么做的

- 新列 `descriptor_LOC` + `descriptor_scope`。
- **数值只出现在 `axis` 以 `C3'` 开头的行**；
  C2 行 / C1 行**一律 `n/a`**（连数字都不放，不是「放了但标注不算」）。
- ★ **判别键 = `axis` 列，不是 `family_kind`**（本役机核发现）：
  seq 15/16 的 `family_kind = extension-family-forward`，但 `axis = C1-*`。
  ⟹ 用 `family_kind` 前缀匹配会把 **C1 行错扫进 C2**。`c2-rows` 模式已写死此注意。

## 四. T2 完整性（既有行 byte-identical）

- **ncols 直方图（改前）**：`{14: 20}` —— **齐**。
  T2 **无** legacy 短 schema 行（那是 **T3** 的前科，记忆律已核，**不误伤**）。
- **改后**：`{16: 20}`，行数 20 不变。
- **写法**：**行级 surgical 追加**（`,val,val` 追加到每条物理行**末尾**），
  **禁 `csv.writer` 全写**（记忆律）。
- **CRLF**：原文件 **CRLF 终止**（20 个 `\r\n`，0 个裸 LF）——
  已保持：改后仍 20 CRLF / **0 裸 LF**（naive writer 会把它悄悄改成 LF 全表污染）。

**byte-identity 证明（强式·回环 md5）**：

```bash
python3 -c "
import hashlib
lines=open('experiments/active/result-tables/T2_C2_ledger_marginal_cost.csv','rb').read().split(b'\r\n')[:-1]
print(hashlib.md5(b'\r\n'.join(l.rsplit(b',',2)[0] for l in lines)+b'\r\n').hexdigest())

```

（新增两列值**皆不含逗号**，故 `rsplit(b',',2)` 剥离精确；

## 五. 措辞（按 17 号承重证据 8）

**禁**：
- ✘ 禁称「律」（**C2 仅两点** = IME 2484 / X-SCALAR 1501·两点不成律）
- ✘ 禁外推曲线

- ✘ 禁把 D1（声明式记录）与机制 (2) 平面 arm（命令式代码）相加
- ✘ **禁事前承诺性能**（PR-37）—— 本报告**零性能主张**
