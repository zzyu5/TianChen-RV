## 二 · 建成的参数化形状（供 iq1_m / iq3_* 复制）

**新文件**（175 行）：
- `include/Weft/Support/GridDecodePlan.h`（98）
- `lib/Support/GridDecodePlan.cpp`（77）

**为什么在 Support**：`WeftConversionRVV --LINK--> WeftRVVDialect`（单向）。verifier 在 Dialect、emitter 在 Conversion，**唯一共同可见层 = Support**（两者都已 link `WeftSupport`）。

```cpp
struct GridDecodePlan {
  llvm::StringRef decodeModel;    // core brick 的 decode_model 属性值
  llvm::StringRef gridArrayName;  // 轴①表名 e.g. "weft_iq2xs_grid"
  llvm::StringRef signArrayName;  // 轴③表名 e.g. "weft_iq2xs_signs64"
  std::int64_t gridEntryCount;    // 轴① 256/512/1024
  GridEntryWidth entryWidth;      // 轴② I64x8
  GridSignPlane signPlane;        // 轴③ Signs64 / Signs256
  GridLsArity lsArity;            // 轴④ Single / Dual —— 选 body leaf
};
const GridDecodePlan *lookupGridDecodePlan(llvm::StringRef decodeModel); // nullptr = REJECT
llvm::ArrayRef<GridDecodePlan> getGridDecodePlans();                     // 渲染诊断用
```

**三处 consumer 全部改吃 registry**（`grep -rn lookupGridDecodePlan lib/`）：
| 层 | 文件 | 作用 |
|---|---|---|
| verifier | `lib/Dialect/RVV/IR/RVVDialectWideningOps.cpp` | 未注册 → REJECT；**诊断由 registry 渲染**，永不与合法集漂移 |
| emitter GEVM | `lib/Conversion/RVV/RVVToEmitCBlockQuantLinear.cpp` | 未注册 → `notifyMatchFailure`；`lsArity` 选 leaf |
| emitter GEMM | 同上 | 同上 |

**fail-closed 没破（[D-1] 未知=拒）**：registry **就是**那个闭集。**放开参数 ≠ 放开合法性** —— 注册表是唯一权威，未注册即拒，且现在是**由构造保证**（一份），而非三份手抄靠人肉同步不漂移。

**表 literal 仍留 Conversion 层**：新增 `emitGridDecodePlanTableDecls(rewriter, loc, plan)` 一处 plan→decl 派发。registry 只**命名**表、不携带 literal ⟹ **signs64 op-attr 阻塞不会复发**。注册行若无 decl 分支 → `failure()`，不会引用未声明的表。

**消除的缺陷类**（不是纯重构）：3 份手抄闭集 → 1 份。改前任一份漏改 = verifier 接受但 emitter 拒（或反之）的静默漂移。

## 三 · 零回归自证（byte-identical）

**方法**（C1 做法）：把**每条 lit RUN 行的 weft-opt 段**在 BEFORE/AFTER **两个 binary** 上重放，哈希产物比对。**1694 条流水线**。

**★harness 自身的诚实性修正**（差点误报 196 条"回归"）：首版 harness 把 binary 命名为 `weft-opt.BEFORE`/`.AFTER`，**argv[0] 泄漏进诊断文本** → 196 条假阳性。**自控（同一 binary 跑两遍）证明 harness 确定性**后才定位到是命名假象。修正 = 两个 binary **同名 `weft-opt`** 置于不同目录 + 路径归一。**假阳性 196 → 2**，那 2 条是真变化（见下）。

复跑（自包含）：

```bash
S=/tmp/c4a && mkdir -p $S/bin-before $S/bin-after
cd /home/kingdom/phdworks/TianchenRV
cat > $S/emit_snapshot.sh <<'EOF'
#!/usr/bin/env bash
set -u
BIN="$1"; OUT="$2"; ROOT=/home/kingdom/phdworks/TianchenRV
BINDIR=$(cd "$(dirname "$BIN")" && pwd)
mkdir -p "$OUT"; : > "$OUT/manifest.txt"; cd "$ROOT"
find test -name '*.mlir' | sort | while read -r f; do
  grep -h '^// RUN:' "$f" 2>/dev/null | sed 's|^// RUN: *||' | while read -r line; do
    stage="${line%%|*}"; case "$stage" in *weft-opt*) ;; *) continue;; esac
    args="${stage#*weft-opt }"; args="${args/\%s/$f}"
    key=$(printf '%s|%s' "$f" "$args" | sha256sum | cut -c1-16)
    o=$("$BIN" $args 2>&1 | sed "s|$BINDIR/||g")
    printf '%s  %s  %s\n' "$(printf '%s' "$o" | sha256sum | cut -d' ' -f1)" "$key" "$f :: $args" >> "$OUT/manifest.txt"
  done
done
sort -o "$OUT/manifest.txt" "$OUT/manifest.txt"; wc -l < "$OUT/manifest.txt"
EOF
chmod +x $S/emit_snapshot.sh
# BEFORE = git stash 后 build 的 weft-opt；AFTER = 当前 build。两者都 cp 成 `weft-opt` 同名。
$S/emit_snapshot.sh $S/bin-before/weft-opt $S/before   # => 1694
$S/emit_snapshot.sh $S/bin-after/weft-opt  $S/after    # => 1694
join <(awk '{print $2" "$1}' $S/before/manifest.txt|sort) <(awk '{print $2" "$1}' $S/after/manifest.txt|sort) \
  | awk '$2!=$3' | wc -l   # => 0
```

## 五 · ★具名缺口：iq1_s repack 前门 **未落地**（本轮 PARTIAL 的诚实处）

**没做到验收里的"iq1_s 能走 repack GEMM 前门 + byte-exact"。不注册、不假装。**

**为什么没注册进 registry**：注册 = verifier 接受该 decode_model。但前门造不出、emitter leaf 也 lower 不了 ⟹ **会 ship 一个"verifier 接受但无人能 lower"的不一致**。故 registry **只注册可达行**（今日 3 行）。同理，`GridEntryWidth::I32x4` / `GridSignPlane::{Ksigns128,TernaryDelta}` / `GridFoldArith::DeltaGrid` **一律不前置声明** —— 未被任何行使用的 enum 值 = 投机泛化，是另一种假。**形状写在本文，不写成没人走的代码。**

### 5.1 iq1_s 真实解码（我从我方**已 byte-exact** 的 block-dot 路核出，非从 ggml 抄）

`lib/Conversion/RVV/RVVToEmitCTernaryBinary.cpp:380-560`，op = `weft_rvv.iq1_s_q8_k_grid_core`，stride **50**（`d@0 | qs[32]@2 | qh[8]@34`），fold_model `scalar_delta_grid`：

```
for ib in 0..7:
    ls    = 2*((qh[ib] >> 12) & 7) + 1          # 轴④ Single，藏在 qh bits 12-14（无 scales[] 平面）
    delta = qh[ib] & 0x8000 ? -1 : 1            # 轴③ 每 sub-block ±1，来自 qh bit 15
    grid  = weft_iq1s_grid[ qs[l] | ((qh[ib] >> 3l) & 7) << 8 ]   # 轴① 11-bit → 2048
    sumi  += ls * Σ(q8 · grid)                  # grid 字节已是带符号 ternary ⟹ 无 sign gather
    sumi1 += ls * delta * (bsums[2ib] + bsums[2ib+1])   # ★读 activation 的 bsums 平面
sumf += d * ((float)sumi + 0.125f * (float)sumi1)      # 轴⑤ 双累加器 DeltaGrid
```

### 5.2 iq1_s 相对 iq2_* 的**三个结构性**差异（不是换张表）

| 轴 | iq2_*（已建） | iq1_s（缺口） | 是否纯 data |
|---|---|---|---|
| ① grid size | 256/512/1024 | **2048** | ✅ 纯 data |
| ② entry width | I64x8 | **I64x8（同宽 ⟹ 这就是 D4 排它第一的理由）** | ✅ 无需改 gather |
| ③ sign 平面 | signs64/256 gather + vmul | **删除 sign gather**；改 ±1 delta × **bsums** | ❌ **删一条 gather + 新增 activation 平面读** |
| ④ ls arity | Single/Dual | Single | ✅ 已有 leaf |
| ⑤ fold | 单累加器 0.125 | **双累加器 `d*(sumi + 0.125*sumi1)`** | ❌ **新增 sumi1 累加器 + 新 fold** |

**⟹ iq1_s ≠ 加一行 registry。**轴③⑤ 要新 body leaf：现有两个 dual/single leaf **都不读 activation 的 bsums 平面**，也**只有一个整数累加器**。

参照体量（**函数起点到下一函数起点的行距**，非花括号配对 —— 本文件闭合花括号有缩进，配对启发式不可靠）：

```bash
grep -n "^mlir::LogicalResult VariantToEmitCFunc::emitRepackGridGem[vm]BodyIq2Xxs(\|^mlir::LogicalResult VariantToEmitCFunc::emitRepackGem[vm]Iq2DualScaleQ8K(" \
  lib/Conversion/RVV/RVVToEmitCBlockQuantLinear.cpp
# 23266 GridGemvBodyIq2Xxs | 23698 GridGemmBodyIq2Xxs | 24252 GemvIq2DualScale | 24699 GemmIq2DualScale
```
⟹ 起点行距 **432 / 554 / 447**（末个 leaf 至文件后续段 ~550）。**四个 leaf 各 ~450–550 行**，iq1_s 需 GEVM + GEMM 两个新 leaf。

### 5.3 还欠的（按序，供下一轮直接接手）

1. **iq1_s repack strip 布局**（x16 block-as-lane：d/ls/delta/grid-index 各平面 offset + stride）—— 现无。
2. **前门构造**：`kGridIq1SScaleModel` + `Iq2GridDecodeFacts` 的 iq1_s 行 + `lowerToRepackGem{v,m}Grid` 走通。
   **注意**：`Iq2GridDecodeFacts` **无 grid 字段**（§一②），且 verifier 现**硬性**要求 `weight_sign_byte_offset > 0`（`RVVDialectWideningOps.cpp:4051` GEVM / `:4108` GEMM，两处）—— iq1_s **无 sign 平面**，此约束必须**按行键控**放宽（需新增 `GridSignPlane::TernaryDelta` + 形如 `plan.hasSignPlane()` 的谓词，**今日两者皆不存在**），**且只对 TernaryDelta 行放宽**（否则等于给 iq2_* 也开了口子 = 拿放宽合法性冒充参数化）。
3. **emitter leaf**：Single-ls + TernaryDelta + DeltaGrid（删 sign gather、加 bsums 读、加 sumi1）。
4. **独立 oracle** `tools/oracle-repack/oracle_repack_iq1_s.cpp`，遵既有 11 例范式（reference 解**原始** block_iq1_s vs emitter-model 读**repacked**）。**[K-5b] 要件③**：oracle **禁与被测物共享解码实现**；**要件①语料完备**：11-bit grid index 取值须覆盖（含 `qh` bit15 两个 delta 极性 + ls 全 8 档），**禁只测退化语料**（前科：P1 oracle 漏负 scale 路径）。
5. **本机无法执行 RVV 向量码**：`qemu-riscv64` 不存在（`ls /usr/bin/qemu-*` 仅 system-x86/img/nbd），本线又**禁上板** ⟹ iq1_s 的 [K-5] 门只能走既有 `tools/oracle-repack` 标量 emitter-model 范式（x86 原生跑）；**emitted-C-on-board 是另一道封印，不由本线冒领**。
