## 1 · iq1_m：四样齐

| 样 | 落点 |
|---|---|
| registry 行 | `lib/Support/GridDecodePlan.cpp`（第 5 行：iq2_xxs/iq2_xs/iq2_s/iq1_s/**iq1_m**） |
| 前门 | `kIq1MDecodeFacts` + `kGridIq1M{,Gemm}ScaleModel`（`lib/Plugin/RVV/FrontDoor/RVVLowerQuantContraction.cpp`） |
| emitter | `emitRepackGemvIq1MQ8K` + `emitRepackGemmIq1MQ8K`（`lib/Conversion/RVV/RVVToEmitCBlockQuantLinear.cpp`） |
| oracle | `tools/oracle-repack/oracle_repack_iq1_m.cpp` |

**3 处 fail-closed 闭集全部显式 arm**（含前科提示的 per-family stride pin）：
1. 抽象 op `scale_model` 闭集 + 诊断串（`RVVDialectWideningOps.cpp`）
2. **per-family stride pin：`isGridIq1MFamily` 显式分支**（不 arm 就落进尾部 q5_K `else` 被 stride 176 拒）
3. loop-body `fold_model` 闭集 ×2（GEVM + GEMM）

### 1.1 axis 复用 = C2 边际成本证据

iq1_m 五个 axis 值里 **四个是复用的**，新增 **1 个**：

| axis | 值 | 新/旧 |
|---|---|---|
| `gridEntryCount` | 2048 | 复用（ggml 的 iq1_m vec_dot 字面 index `iq1s_grid`） |
| `entryWidth` | `I64x8` | 复用 |
| `signPlane` | `TernaryDelta` | 复用 |
| `lsArity` | `Dual` | **复用自 iq2_xs/iq2_s**（跨 family 复用） |
| `foldArith` | `DeltaGridGroupSum` | **新** |

### 1.2 为什么 fold 必须是新值（不是 iq1_s 的参数）

末端 float 折叠**表达式相同**（`sumf += d*(accA + 0.125f*accB)`）。但 accB 的**构造**不同，且不可调和：

- **delta 粒度**：iq1_s 每 32 元素 sub-block 一个 ±1（qh bit15）；iq1_m 每 **8 元素 group** 一个，
  一个 sub-block 四个，且是**独立 bit**（`qh[l/2]` 的 0x08 / 0x80）。
- **delta 项的激活因子**：iq1_s 要 32 个激活之和 = `bsums[2ib]+bsums[2ib+1]`，所以它读 bsums。
  iq1_m 要 **per-8 group sum**，而 block_q8_K 的 bsums 是 **每 16 个**一组
  （ggml-common.h:364 `int16_t bsums[QK_K/16]`）。一个 bsums 项里的两个 8-group **带独立 delta 符号**，
  ⟹ **bsums 对 iq1_m 不是"没用到"，是"表达不了"**。iq1_m 因此**不 stamp
  `activation_bsums_byte_offset`**，group sum 由 kernel 内从同一批激活标量累加。

**这条不是断言 —— 是实测的**（见 §2 的 `BSUMS16` 负控，spike 100%）。

### 1.3 iq1_m 的 repack 布局（本线设计）

ggml `block_iq1_m` = 56 B `qs[32]+qh[16]+scales[8]`，**没有 inline `d`**（fp16 由四个 nibble 散落在
scales 里拼装）。repack 把拼装 + qh/scales 解码一次做完：

```
d[16]            fp16 @ +0     (32 B)   ASSEMBLED iq1m_scale_t
ls[8][2][16]     int8 @ +32    (256 B)  ls1/ls2（iq2_xs 的 (ib*2+gh)*16 形状）
delta[8][4][16]  int8 @ +288   (512 B)  PER-GROUP ±1（骑 sign-plane 槽位）
gidx[8][4][16]   u16  @ +800   (1024 B) qs[l] | ((qh[l/2] << (8-4*(l%2))) & 0x700)
------------------------------------------ stride 1824
```

`quant_byte_offset = 0` —— **grid 家族里唯一的 0**（其余全是 2 = "qs 跟在 inline fp16 d 后面"）。

## 2 · byte-exact（oracle 独立 + 语料 MEASURE）

`g++ -O2 -std=c++17 tools/oracle-repack/oracle_repack_iq1_m.cpp -o /tmp/oracle_iq1m && /tmp/oracle_iq1m`

**终判**：`VERDICT BYTE-EXACT-INTEGER`，exit 0。

**三个整数证书**（只查一个会让某机制不设防）：
- `sumi1` = dual-ls 三元 grid dot
- `sumi2` = per-group `ls*delta*groupSum`
- `scale_u16` = nibble-scatter 拼装 —— **穷举 65536/65536**（该拼装的输入域就是 4 个 nibble = 16⁴，
  所以这不是抽样、是全域；每个组合的低 12 bit 随机化，证明拼装不泄漏 ls 字段）

**oracle 独立性**：reference 读**原始 packed** block_iq1_m、read time 现解 qh/scales、走
`(const int8_t *)(iq1s_grid + idx)` 的 uint64 reinterpret、并保留 **ggml 自己的折叠分组**；
emitter-model 读 **repacked strip**、`grid_bytes[idx*8+j]` 平表 gather、走 **emitter 的 per-group 折叠**。
scale 两侧derivation 不同（ggml 融合表达式 vs 逐 nibble 循环）。唯一共享物 = `iq1s_grid` 常量本身。

**语料完备（oracle 自己 emit，非声称）**：
```
grid_index : 2048 / 2048 distinct 11-bit indices exercised   COMPLETE
delta[g0]  : +1 28864 groups, -1 28864 groups   BOTH POLARITIES
delta[g1]  : +1 28864 groups, -1 28864 groups   BOTH POLARITIES
delta[g2]  : +1 28864 groups, -1 28864 groups   BOTH POLARITIES
delta[g3]  : +1 28864 groups, -1 28864 groups   BOTH POLARITIES
ls1        : ls=1:7216 ls=3:7216 ... ls=15:7216
ls2        : ls=1:7216 ls=3:7216 ... ls=15:7216
scale_u16  : 65536 / 65536 nibble combinations EXHAUSTIVE, mismatch=0  BYTE-EXACT
```
delta **逐 slot** 统计（四个 bit 独立，只统计合计会让 slot 1-3 不设防，也会让 §2 的 BSUMS16 静默失效）；
ls1/ls2 **分开**统计（dual ls，合并统计可能 ls2 从没通电）。

**负控（oracle 内，扰动 reference）—— 全部 EXERCISED**：

| 控制 | sumi1 | sumi2 |
|---|---|---|
| GRID (idx 旋转 +457) | 1280/1280 (100%) | 0 |
| QHHIGH (丢 qh 高 3 bit) | 1120/1280 (88%) | 0 |
| LS1 (只扰 ls1) | 1280/1280 | 1280/1280 |
| LS2 (只扰 ls2) | 1277/1280 | 1280/1280 |
| DELTA (四个 delta 全 +1) | 0 | 1280/1280 (100%) |
| **BSUMS16**（强制一个 16-group 内两个 8-group **共用** delta = per-16 bsums *能*表达的东西） | 0 | **1280/1280 (100%)** |

**BSUMS16 是把 §1.2 的设计断言变成实测事实的那一个。** 它若不 spike，`DeltaGridGroupSum` 这个
axis 值就不成立、iq1_m 就该做成 iq1_s leaf 的参数。它 spike 100%。

## 3 · ★ iq3_xxs：i32x4 "非平移"的代码级刻画（本轮未落地 iq3，只侦察）

### 3.1 直觉的读法是错的

"I32x4 = 把 gather 的移位 3→2、内层 j 循环 0..7→0..3" —— 这两条**确实**只是参数。但**它们不是工作量**。

### 3.2 真正非平移的是 **每 8 元素 group 的 entry 条数 1 → 2**

| | 每 group 的 grid entry | 证据 |
|---|---|---|
| iq1_s (I64x8) | **1** | `grid = iq1s_grid + idx; for j<8: q8[j]*grid[j]` |
| iq3_xxs (I32x4) | **2** | `grid1 = iq3xxs_grid + q3[2l+0]; grid2 = iq3xxs_grid + q3[2l+1];`<br>`for j<4: grid1[j]*q8[j+0] ... grid2[j]*q8[j+4]` |

—— 因为 4 字节 entry 只覆盖半个 group。

**独立算术核对**（`block_iq3_xxs.qs = 3*QK_K/8 = 96` B，在 `QK_K/4 = 64` 处切分）：
```
grid-index 区 = 64 B ; aux32 区 = 32 B = 8 × uint32 = 每 sub-block 1 个
每 sub-block grid 索引 = 64/8 = 8   （与 ggml 自己的 q3 += 8 一致）
每 sub-block group 数  = 32/8 = 4
⟹ 每 group 索引数 = 8/4 = 2
```

**后果（两条，都不是常量改动）**：
1. **grid-index strip 翻倍**：`gidx[8][4][16]` = 512 u16/列组 → `gidx[8][8][16]` = 1024。
2. **最内层 nest 要改结构**：现在的 emitter 每 group 提**一个** `gridBase` 然后 `for j<8` 打它
   （`RVVToEmitCBlockQuantLinear.cpp` 的 `gridBase[h] = shiftIdxU16(gidxU16);` + `for (int64_t j = 0; j < 8; ++j)`
   在 5 个 grid leaf 里同构重复）。i32x4 要**两个 base + 激活区间劈半**。
   ⟹ **新 leaf，不是新常量。**

### 3.3 另一条真差异：末端常量

iq3_xxs 是 `*s = 0.25f * sumf`（store 侧 0.25，不是 0.125）。形状是 `SignScaleEighth` 的，
但那个 enum 值**字面就叫 Eighth** ⟹ 要么参数化常量、要么拆值。

### 3.4 ★ 侦察证伪了仓库里既存的一条投机断言

C4a / C4a-2 的 header + registry 注释白纸黑字写着 iq3_xxs 需要一个新的
**`GridSignPlane::Ksigns128`**。**代码不支持这个说法**：

- iq3_xxs 的符号面是 `ksigns_iq2xs[(aux32 >> 7l) & 127]` 经 `kmask_iq2xs[j]` 测试；
- iq2_xxs 的是 `ksigns_iq2xs[(aux32[1] >> 7l) & 127]` 经 `kmask_iq2xs[j]` 测试 —— **同一机制**；
- 而 `GridSignPlane::Signs64` **已经就是**这个面：`kIQ2XXSKsigns` 是
  `std::array<std::int32_t, 128>`（ggml `ksigns_iq2xs` 原样，`RVVMonolithicBlockDotFamily.h:1050`），
  emitter 展开成 `weft_iq2xxs_signs64[1024]` = **128 selector × 8 个 ±1 字节**。

⟹ **iq3_xxs 会复用 Signs64，不需要 Ksigns128。** 顺带：`Signs64` 的 doc 原文写
"DERIVED **64-entry** ±1 plane" 是**错的**（表是 128×8=1024；"64" 指每 selector 产出的 **64-bit** 符号字），
而这条错 doc 很可能就是当初误导出 `Ksigns128` 的源头。本轮已改正 doc、并删掉 Ksigns128 的前置声明。

**这条本身是"禁投机泛化"的教材**：规则写的是 **enum 不许有无真行使用的值**，
而投机**没被挡住 —— 它搬进注释里活了两轮**。iq3_xxs 现在只欠 `GridEntryWidth::I32x4` 一个值。

### 3.5 为什么本轮不落 iq3_xxs

落齐要：新 entry-width 值 + 新 strip 形状 + 劈半的内层 nest（2 个新 leaf）+ fold 常量拆分
+ 新 oracle。**规模 ≈ 又一个完整 C4a-3。** 按"宁可 iq1_m 一格真，不要两格假"，本轮停在侦察。
**未破坏任何 i64x8 既有格**（§4 零回归 = 0）；§7 的"若改动会回归既有格就停手"未触发 —— 因为**没动**。
