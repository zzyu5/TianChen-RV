## 三、★核心判据：为什么"双板 diff"不能写成文件 diff（空心门规避）

**registry 是板无关的**：`schema/pattern-registry.v1.json` 是**一个文件**，**不存在按板分身**。因此把 [PAT-3]「diff 注册表 = 0」直译成"diff 两份板注册表"——**没有第二个操作数**，等于拿文件和自己比，**永远打印 0**。那是**平凡真 = 空心门**：**永不可能变红 ⇒ 什么都没证明**。空心门比没有门更坏（把未证性质洗成一个绿勾）。

**本门改判**：把**同一注册表**对**两份真实板能力事实实例**做**解析（resolve）**，再对**解析结果**判 [PAT-3]。

### 三.1 板能力事实 = 从真实已测快照派生（**非杜撰**）

来源 `schema/measurement-memory.v1.json` 的 `rows[].snapshot`（**只读**）：

```bash
python3 -c "
import json
from collections import Counter
d=json.load(open('schema/measurement-memory.v1.json'))
c=Counter(json.dumps(r['snapshot'],sort_keys=True,ensure_ascii=False) for r in d['rows'])
print('DISTINCT snapshots:',len(c))
for k,n in c.most_common(): print(f'  n={n:3d} {k[:150]}')
"
```
实测输出：**5 个 distinct snapshot**，覆盖两块真板 —— `openEuler-VLEN128`（vlen 128 · march `rv64gcv`）与 `SpacemiT-K1-VLEN256`（vlen 256 · march `rv64gcv` 及 `rv64gcv_xsmtvdotii1p0`）。

**派生规则（机械 · 不杜撰）**：`rvv.v` ⟸ march 匹配 `rv64g?c?v`；`ime.present` ⟸ march 含 `xsmtvdotii`（opt-in token，任一快照带 token 即该板有 IME）。**其余谓词**（`rvv.zvfh` / `rvv.zvfhmin` / `format_capability` / `shape_fact:M<M_star`）**无法**从快照记录派生 ⇒ 解析为 **`unknown`，不编造 true/false**。`unknown` 是合法键值：[PAT-3] 约束的是**条目体**，不是谓词真值。

### 三.2 五条判据（G1–G5）与**分层豁免**

| 层 | 字段 | 板字面量 |
|---|---|---|
| **entry-body**（条目体） | `pattern_id` `transform` `status` `milestone` `brick` | **禁止** |
| **key**（键） | `requires` `discriminant_capability_fact` | 只许能力键 · **禁板身份** |
| **evidence**（证据） | `metrics_hook` `mechanism` `measured_negative_boundary` `restart_condition` `phase_note` `xfer_note` `xfer_classes` | **预期存在**（指向板 casefile / 记录板上证伪） |
| 层外新字段 | — | **fail-closed 红**（per-board override 正是从这里混进来） |

★**分层是本门不误报的关键**：若粗暴判"注册表任何位置出现板字面量即红"，会在 **12 处合法证据**上打出假红（见 §四.2）。

- **G1 无 per-board override 通道** + 未分类字段 fail-closed —— **「零条目改写」的承重形式**：条目只有在**存在**按板改写通道时才**可能**被按板改写。
- **G2 条目体双板不变** —— ★**诚实**：今日 schema 下 G2 **由 G1 蕴含**（无 override 通道 ⇒ 解析即拷贝 ⇒ 体不可能异）。**G2 今日不是独立牙齿**，是 G1 守护的不变量；一旦将来长出 override 通道，G2 才承重。**报为 `entailed`，不冒充证明**。
- **G3 `transform` 板洁净** —— `transform` = 构造指针 = 条目本体，**禁板身份字面量**。**非空洞**：注册表**满是**板字面量（证据层 12 处），G3 断言的是它们被**关在条目体之外**。
- **G4 禁板身份做键** —— `requires` 不得以 board/board_id/march/vlen 为键；选择必须走**能力键**（[PAT-3]/C1 精神：capability-keyed，非 board-branched）。
- **G5 反空洞** —— 至少一行的**键值必须真的跨板不同**；否则"双板解析"是 no-op 拷贝、G1–G4 **空洞变绿**。**这是门自带的空心检测器**。
