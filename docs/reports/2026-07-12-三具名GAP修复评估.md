## 0. 一句话结论 + 排序

**三 GAP 无一是"现在做"的性能立项**——三者在各自【被测面】的 Amdahl e2e 上限**全在噪声地板之下**（<0.15% / <0.6% / <0.4%，皆 << ~1–1.5× 噪声），按 canon 规则 4 与立项 pre-check 均**只能以机制/方法学名义**存在，全部归 **LAW-FIRST-EMISSION 的 C3′ 档案**（perf-covered 新增绿格 = 0，与 ROADMAP "perf-covered 只经接线/e2e 战役移动、不经流式/逐元素 micro" 一致）。

**最值得（未来）投入的是 `GAP-CLANG-GATHER-TRAP`（iq4_nl）**——它是**唯一带真赢潜伏-邻接（latent-win-adjacent）**的一条：被测叶子（iq4_nl 流式 dequant）本身 e2e-null，但**同一 `uarch.gather_slow` 键控杠杆外推到热 vec_dot iq 族 gather**（batch2c 全对称-fair LOSS，在 iq 模型 matmul 热路径上）——那是三者中**唯一能触达 e2e 的邻接面**（虽只争 parity-recovery、iq 是少数部署）。它同时（a）机制**objdump 已证**（三者中唯一满足性能宪章规则 1）、（b）C3′ 价值最高（把 canon 具名-但-未建的 `uarch.vrgather_slow` P6 quirk 表从抽象工作项落成板测动机案 + 给律文添**新的第 5 根因类**）、（c）有 **scalar-pin 安全地板**（byte-exact 保持，把脆弱的 gcc-autovec 4.83× 意外转成 robust、emitter-owned）。

## 1. ① GAP-CLANG-GATHER-TRAP（iq4_nl 流式 dequant）— 排名第一

**casefile**：`813f6462`·`covering-batch3-stream-rvv/{opponent_probe.md,MANIFEST.md,raw_board_results.txt}`。iq4_nl 16-entry 非线性码本流式 `dequantize_row`，rvv/SG2044/VLEN128，byte-exact（maxrel 0）。

- **根因（MIXED·emitter-maturity + 可路由 uarch quirk·非物理墙·非撤回-S6）**：两耦合因。(a) **发射器不拥有 lowering**——码本解码发射成通用 scalar C（函数局部 `static const int8_t kvalues[16]` + 指针推进下标·零 RVV intrinsic·`RVVToEmitCForwardElementwise.cpp` codebookLoad@3504 + IQ4NL 分支@3821-3855），向量化决策**外包给部署编译器**（autovec roulette）：clang-18 自动向量化成单条 `vluxei32.v` 索引内存 gather → **0.545 GB/s**；gcc-15 保 scalar（32 lb + 16 lbu）→ **2.79 GB/s**。(b) **uarch quirk**——SG2044 上 `vluxei` 索引 gather 比 16-entry scalar 表查（表驻 L1/reg）慢 ~5×。canon 已具名此类事实为 `uarch.vrgather_slow`（科研目标总纲v2 S-1 / 执行总纲v2 S-4·P6 键控 grep=0·标 C3′ 增量）→ quirk **可路由**（更快 lowering 存在，gcc-ours 2.79 GB/s 已证），非墙。objdump（raw_board_results.txt）+ 源读一致。
- **可修性**：emitter-maturity·capability-keyed·family-replicable，合 LAW-FIRST-EMISSION 元结构，但**扩律出第 5 根因类**——四例（K-quant S6 regfile-spill / col-outer 冷重读 / vl16 半宽 / IME leaf-pipeline vsetvli-churn）皆"逐片段/逐块发射仪式开销"；本例是"**lowering 选择不被拥有 / 部署编译器 autovec 选中 uarch-hostile 原语**" + 可路由 uarch quirk。同律元形、新机制。机制 confidence **高**（objdump + 源读一致·3× 稳定复现·IQR 0.39/3.05）；杠杆落地成赢 confidence **中**（scalar-pin 地板安全；register-vrgather 备选**不确定**——canon 自己的事实就叫 `uarch.vrgather_slow`，寄存器 permute 可能也被 trap，需板测）。
- **修法草案**：让发射器**拥有码本 lowering**，键控新事实 `uarch.gather_slow`（实例化 canon 具名-但-未建的 `uarch.vrgather_slow` P6 quirk 表·provenance=vendor_table/measured·trust=measured@SG2044）。**安全地板杠杆（推荐默认）**：`uarch.gather_slow` 成立时，把码本解码发射成 clang **不会**auto-vec 成 gather 的形状（scalar-pin：`#pragma clang loop vectorize(disable)` 或强制 scalar 结构）→ gcc 与 clang **双双**产出已证快的 scalar 表查（~2.79 GB/s），把赢从 gcc-autovec 意外转成 **robust · emitter-owned**（clang 部署 0.94×→~4.8×）。**备选杠杆（需先板测）**：路由到 vec_dot FP4 核已用的 register-resident 16-entry vrgather（`RVVToEmitCCodebookFp4.cpp:252 __riscv_vrgather_vv_i8m1`·VLEN128 下 16-entry i8 表 = 恰一 i8m1 vreg = 寄存器 permute 非内存 gather）——但 canon quirk 名即 `vrgather_slow`，可能也 trap → 采用前先测。族级复制到全部 16-entry 码本叶：iq4_nl/iq4_xs/mxfp4/nvfp4。字节等价保持（解码算术不变，仅 vec/scalar 形状移动）。
- **Amdahl 上限（被测面）**：**噪声地板之下 → 性能名义禁·仅机制/方法学**（canon 规则 4）。`dequantize_row(iq4_nl)` **非 matmul 热路径**（iq4_nl 推理走 `ggml_vec_dot_iq4_nl_q8_0`；dequant-row 仅服务 get_rows/embedding + 罕见 weight→f32），<~0.5% decode/prefill。满 5×（0.545→2.79 GB/s）：e2e 上限 ≈ 0.5% × (1−1/5) ≈ **0.4% < 噪声地板**（~1%·T-N_noise_floor.csv·自检 IQR 0.14–0.19%·门=hist-floor×1.5）。★**同域纪律**：部署账用 clang-deploy 0.94×（非 gcc 4.83×）喂 Amdahl，否则即 [CASE-COMPILER-ASYMMETRY] garbage-in。
- **★真赢潜伏（本报告唯一带真赢标记者·PARTIALLY 真·非 e2e 头条）**：两层：(1) **被测叶子上**——4.83× 是**脆弱的 gcc-autovec 意外**（gcc 恰把我方源 scalar 化、把 ggml 源向量化），非 emitter-owned，gcc bump 即可翻；scalar-pin 把它转成 **robust · emitter-owned ~4.8×**，在 clang 部署路径也活。但仍 **KERNEL-AXIS · 冷算子 → 无 e2e 触达 → 仅机制名义**。区别于撤回-S6 [CASE-COMPILER-ASYMMETRY]：S6 的 1.884× 是 compiler-非对称（clang-ours vs gcc-shipped）、对称 gcc/gcc 蒸发到 0.272×；这里 4.83× **本就是对称 gcc/gcc 数、不蒸发**，是**非对称/clang-deploy 数（0.94×）不利**——正镜像（那里 clang-ours 虚高，这里 clang-ours 压低），casefile 双账本诚实披露。(2) **★邻接真赢**——同一 `uarch.gather_slow` 键控杠杆外推到**热 vec_dot iq 族 gather**（T8 batch2c：iq2_xxs 0.78×/iq3_s 0.28×/iq3_xxs 0.16×/iq4_xs 0.72×·全对称-fair LOSS·"per-subblock gather/redsum 未 batch"·在 iq 模型 matmul 热路径）。**该面 CAN 触达 e2e**（对 iq 模型），但争 parity-recovery 非头条倍数、iq 是少数部署，且是**分离的已具名 gap 族**（非本 GAP）。"成真 e2e perf 赢" confidence **低**。
- **工程量**：被测 GAP **低-中**（scalar-pin 分支@3821-3855 + 1 个 `uarch.gather_slow` fact + P6 键 + 4 叶族复制·字节重验廉价·1 次板重测确认 0.94×→~4.8×）。扩到热 vec_dot iq 族 **中-高**（batch2c "per-subblock-gather-not-batched"·batch gather/redsum over super-block 是较大 emit-重构）。若选 vrgather 备选：**前置** 1 次 SG2044 板测（本地不可跑·canon 警告可能也 trap）。
- **C3′ 价值（高·独立于 null e2e）**：(1) 干净档案点"能力键控须延伸到部署编译器 autovec 选择 AND 到 per-uarch quirk"——LAW 下**第 5 个 distinct 根因类**（deploy-autovec-roulette + 可路由 uarch quirk）。(2) 直接实例化 canon 具名-但-未建的 `uarch.vrgather_slow` P6 quirk 表增量（grep=0·标 C3′）——把抽象 roadmap 工作项转成具体、板测、带"走表不走 if"修法的动机案。(3) 一案齐演性能宪章三件套：反汇编认瓶颈（objdump 归因）+ per-format 板测定（gcc/clang 分裂直觉不可见）+ 同域 Amdahl（部署=clang 因子）。(4) 通过展示撤回-S6 非对称的**诚实正镜像**、锐化 compiler-对称双账本教义（双账本抓的是"脆弱-但-真"的赢而非假赢）。

## 2. ② GAP-DEQ-KQUANT-UNPACK（q4_K/q5_K 流式 dequant）— 排名第二

**casefile**：同 batch。流式 `dequantize_row_q4_K`，kernel-轴对位 ggml 自己 dispatch 的 `dequantize_row_q4_K`（板 libggml-base.so md5 1b4580c4·gcc-15）。byte-exact（maxrel 0）。比值 ours/opp：deploy(clang-18) **0.879×**·kernel(gcc-15-对称) **0.636×**。roofline "mem-bound scale-unpack 3.0 GB/s" vs opp 3.4（< q8_0 的 3.7）·IQR 1.73/8.25（不稳）。出口 = named-gap，**非**物理 parity、**非**正确性/算法缺陷。

- **根因（scalar 发射仪式·非 scale-unpack 本身·非物理墙·非 clang codegen 错）**：`emitGgmlDequantizeRowExtended` 的 Q4K/Q5K 分支（~4055）。`get_scale_min_k4` 编译期展开（8 廉价 6-bit 抽取/super-block·**非**瓶颈）。256-elem 解码 = 八个 scalar `elemLoop(32)` runtime 循环：每 iter 做 loadIntAt（指针推进 + 下标[0] 字节读）/ iAnd/iShr nibble peel / i2f cast / scalar fMul/fSub / storeF32At——**零 RVV intrinsic**（grep 证：分支内无 vsetvl/vle/vse）。对手 ggml `dequantize_row_q4_K` **也是** scalar 参考（base type-traits to_float），但是紧凑手写循环（`q+=32; *y++ = d1*(q[l]&0xF)-m1`）。我方 emitc idiom 生成比 ggml 紧循环更重的逐元素地址算术 + int-domain cast → 掉到内存墙以下（q4_K 每 elem 读入字节约 q8_0 一半，GB/s 却更慢 → 非纯带宽受限，解码 compute 侵入）。**非**物理墙、**非** clang codegen 错、**非**指令微质量。
- **可修性**：emitter-maturity·capability-keyed·family-replicable，**但性能上限低（mixed）**。同 LAW-FIRST-EMISSION（byte-exact-正确首发·逐片段仪式不成熟·可具名 GAP·能力键控+族级杠杆）→ **第 5 例 CANDIDATE**，但**弱于四正例**：例 1/3/4 有真 compute-bound 或 e2e-传导的潜伏赢；这里算子 (a) 贴内存墙 (b) off 热 matmul 路（q4_K matmul 走 block-dot/vec_dot·非 dequant-row；dequant-row 仅服务 get_rows/conversion）→ 杠杆把黄格关到 ~parity 但 e2e ~null。属"named GAP fixable"黄格桶但 perf 值封顶在方法/机制。与 wide-LMUL K-quant Win-A 杠杆（[[emitter-maturity-vluxei16-widelmul]]·瞄 vec_dot/GEMM 整数核 emitQ4_KSuperBlockAux32Core）**不同**——本流式解码叶独立、全 scalar（尚未 LMUL 参数化）。
- **修法草案**：向量化 Q4K/Q5K 流式解码叶（~4055）。每 32-elem sub-block：vle8 qs 字节·vand 0x0F(低半)/vsrl 4(高半)·vzext SEW8→SEW32·vfcvt.f·vfmul by scalar-splat scale d1/d2·vfsub scalar-splat min ml1/ml2·vse32。`get_scale_min_k4` 保 scalar（8 值/super-block·廉价·per-sub-block splat）。q5_K 加 qh 第 5 位注入（splat qh mask 上 vand/vsll）——已是分支内 sibling。能力键：SEW8→SEW32 widen·LMUL 键控 VLEN·**复用**已证的 repack coreLmul threading + `emitQ6_KSuperBlockAux32Core`(RVVToEmitCKQuant.cpp:30) 已有的 e8m2 unpack idiom + name-builders(riscvIntrinsicName)——**无新原语 = 低机制**。族级：q2_K/q3_K/q5_K/q6_K 共此函数内同一 scalar super-block 解码骨架 → 一个向量化-解码 helper 惠及整个 K-quant 流式族。★**已知正确性陷阱（必守）**：VLEN-agnostic widen/fold——wide-LMUL K-quant 工作已撞过 first-cut vget 形式 VLEN128-only、trellis-check 抓到 VLEN256 上 FAIL ~25–50%；用 vslidedown-by-element-offset fold，任何 perf 主张前 gate on rvv-VLEN128 + k1-VLEN256 byte-exact lit。
- **Amdahl 上限**：噪声地板之下 → 机制/方法学名义 ONLY（canon 规则触发）。fraction：`dequantize_row_q4_K` **off 热 matmul 路**（q4_K matmul dispatch 到 block-dot vec_dot / repack GEMM·从不 row-dequant）·dequant-row 服务 get_rows/embedding + 偶发 conversion·~<1% decode 相（**精确 fraction 本处未测**——T6 e2e 表空/仅 projection·<1% 是 dispatch-definitional 非实测 phase 分解·低 confidence 精确%、**高** confidence 定性 <噪声）。预期局部改善：kernel-轴 0.64–0.88× → ~1.0–1.2× parity-ish（内存墙封顶·对手也 scalar）。e2e 上限 ≈ frac(<1%) × (1−1/1.2) ≈ **<0.15% << 噪声地板**。同 G2 fusion e2e-null（norm 0.05% × fusion → +0.05% < 噪声）与例 2 decode washout 原型。
- **真赢潜伏**：**无**——iq4_nl GAP-CLANG-GATHER-TRAP 的**反面**。iq4_nl 对称账翻 4.83×（真·clang-blocked）；q4_K 对称账 **0.636×**——比 deploy(clang) 0.879× **更深**。两账本皆 <1，公平对称账是**更狠**那个，clang 恰把我方 scalar 解码编得相对好（故 shipped 0.879× 比公平 0.636× 没那么糟）。无 clang artifact 撑假赢、无 gcc-对称赢被 clang 遮。**genuine emitter-maturity gap，非 [CASE-COMPILER-ASYMMETRY]、非撤回-S6**。confidence 高（双账本皆实测·皆 sub-parity·objdump 一致 scalar 两侧）。
- **工程量**：中。触碰集 1 文件（Q4K/Q5K 分支 ~4055）+ 共享向量化-解码 helper·复制到同函数内 q2_K/q3_K/q5_K/q6_K 叶。**跨线共享文件**（[[parallel-lines-need-disjoint-files]] 必串行·不并行）。麻烦点 = VLEN-agnostic widen/fold 正确性（已知陷阱·trellis-check 必 gate：rvv-VLEN128 + k1-VLEN256 byte-exact lit BEFORE 任何板 perf run）。低机制（复用 name-builders + e8m2 idiom·无新 op/attr）。板重验 = clean rebuild 后重跑已建 covering-batch3 stream_paired harness。

## 3. ③ GAP-FWD-M8-VSETVL（add/mul 前向逐元素）— 排名第三
