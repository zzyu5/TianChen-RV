## 四、分层标注归一 —— 裁定：**只登记，不改**

**总令要求**：status ∈ {mechanized | planned | measured-negative | **deferred**}。**registry 现用** `deferred-backlog`。

**核实：这是 `$meta`/schema 措辞吗？→ 是。**

`schema/pattern-registry.v1.json` 的 **`$meta.note` 自身声明了 enum**（机算可提取，脚本 `probe_registry()` 正则 `status ∈ {…}`）：

```
status ∈ {mechanized|partial|planned|measured-negative|deferred-backlog}
```

且 `$meta.note` 用**整段定义**把 `deferred-backlog` 与 `planned` 严格区分：
> *"status=deferred-backlog is a NAMED salvage/optimization path that is NOT mechanized … explicitly PARKED with a restart_condition + evidence pointer -- **distinct from `planned`** (a scheduled brick in the CURRENT milestone): a deferred-backlog row reopens only when a FUTURE campaign reproduces its bottleneck with NEW evidence."*

**⟹ 裁定：`deferred-backlog` 属 `$meta` 声明的 schema 措辞，非单纯条目 status 字段值。**

改名 `deferred-backlog → deferred` 会连带：① 改 `$meta.note` 的 enum 声明串；② 改 `$meta.note` 的定义段（该段正**依赖 backlog 后缀**承载"与 planned 的区别"语义）。二者皆 **canon/schema 级措辞变更**。

按 brief「若属 $meta 硬冻结 → 只登记不改」+「拿不准 = 保守：不改，登记」：
**→ 本轮 registry 文件零改动（`git diff schema/` 为空）。以下两项登记待用户裁：**

| 登记项 | 事实 | 建议（待裁·不自行执行） |
|---|---|---|
| **[C7-REG-1]** `deferred-backlog` vs 总令 `deferred` | enum 声明在 `$meta.note`；1 条在用（`WIDE-DECODE-register-resident-salvage`） | 二选一：(a) 总令措辞放宽认 `deferred-backlog`（**推荐** · 零改动 · 且后缀承载真语义）；(b) 若须改名，同步改 `$meta.note` enum 串 + 定义段 = canon 级动作 |
| **[C7-REG-2]** `partial` 声明但零实例 | `$meta.note` 声明 5 值，实际用 4 值；`partial` 直方图计数 **0** | 总令的 4 值集合**不含** `partial`。建议裁：`partial` 是否退役出 enum（canon 级 · 不自行动） |
