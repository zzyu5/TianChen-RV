## 0. 总目标 · 骨架 · 基线

**[G-0] 终极目标**：建成一个以"能力事实"为**唯一决策源**的 RISC-V 执行层编译器——接入一个新扩展家族 = 一个插件 + 几行表格，核心零改动；kernel 主体由机制构造（强义，见 [L-8]）而非手写；每一次变体选择可归因；每一条结构性主张机器可检验。学术上支撑三条贡献（C1 合取存在性 → 可复制协议；C2 泛化代价 → 边际成本规律；C3′ 能力键控模式库 → 带实测与迁移的模板）；工程上以覆盖率与正确性门槛成为该负载域内**真正可用的编译器**。

**[G-1] 双轴骨架（组织原则）**：
- **引擎轴**——机制覆盖广、主体由机制构造、可跨家族（N-operand 统一、全 zoo 构造、资源感知选择、真硬件探测、性能击败）。
- **证据轴**——每条结构性主张机器可检验（schema 冻结哈希、归因日志、模式注册表作数据、自动成本账、覆盖率进 CI、硬件探测）。
- **裁定**：成熟度指标**进 CI，不进 slides**。引擎轴让它成为成熟编译器；证据轴让成熟度可被机器证明为论文证据。两轴并列为交付，任何一轴单跑都不构成里程碑。

**[G-2] 定位红线**：执行层 / 编译后端层（Triton-backend 类比层）。负载域 = ggml/llama.cpp 型量化 LLM 推理 kernel。覆盖率分母**永远是本负载域 kernel 清单**（[COV-1]），防止向 TVM 式端到端框架漂移。

**[G-3] 基线假设**（本纲写作时视为已成立的前提；agent 每轮先确认，任何一条失效即上报并冻结相关条款评估）：
- **[B-1]** N-operand 通用路由描述符对**产品-归约形状族**已达成端到端字节精确（含 offset-binary 三操作数与查表 N=3）；掩码/比较前缀变体**显式排除**为声明边界。
- **[B-2]** 全部块量化点积格式已经统一表驱动入口 + 能力调度 scaffold 接线（dispatch-wired）。
- **[B-3]** **双发射路径共存**：(a) 单体块量化算子 → 平面 body 发射器（描述符**选择**）；(b) 分解式 N-operand 构造路（production-e2e）。收敛目标见 [K-0]/[K-3b]。
- **[B-4]** 平面 body 参数化完成；码本参数化未启动。
- **[B-5]** 编译期选择阶段归因原料丰富（偏好分/名次/解释/并列判据/选择理由）；调度阶段（LMUL 选择）与合法性阶段的归因缺失或未核实。
- **[B-6]** 冷启动分 = 每插件常量（非能力先验，族内无区分）；向量/矩阵两家族**现**不为同一内核竞标——该前提在 P7 落地时失效（→ [SEL-2] 硬时序）。
- **[B-7]** implies 现查一层直接依赖；传递闭包修复已核**对现有判定字节中性**（现有声明全为一跳）。
- **[B-8]** 资源感知成本模型、真硬件探测两支柱未启动。

**[G-4] 快照纪律**：本纲零现值。凡数字（覆盖率、燃减、家族状态、性能）只出现在 CI 报告/内部稿，且必须携带快照 ID。

## 1. 措辞与主张宪法（写作、注释、slides 同守）

- **[L-1]** 无限定的 beat/outperform 全文禁止；性能主张必须绑定**相（prefill/decode）× 板 × 格式 × 基线 commit**。
- **[L-2]** "依赖式分层"只作被刻画对象，永不作发现（SubtargetFeature.Implies 在先）；术语用 **integrated（复用向量寄存器堆）/ independent-attached（独立寄存器堆）**，可引 Kulagin 2025。
- **[L-3]** 跨越用"**范式**（paradigm）"，独立性用"**家族**（family）"，不得混用；keystone 的准确表述 = "向量核上的矩阵**范式**"。
- **[L-4]** 不与 autotuning 对标；唯一允许句式：能力键控**裁剪并结构化** autotuner 要搜索的空间，互补而非替代。
- **[L-5]** 作废数据清单：06-14"输给 naive"永久作废；board-pending 期间旧性能格子不得进任何文本。
- **[L-6] 成熟度三重区分**：①"能被能力调度路由"≠"主体由机制构造"（wiring ≠ construction）；②"击败朴素/标量基线"≠"击败框架自身同 ISA 内核"（vs-naive ≠ vs-framework）；③"编译期/lit 证据"≠"硅上封存（反汇编/实测）"（export-lit ≠ silicon-sealed）。
- **[L-7] Win 登记制**：性能事件必须登记命名（Win-A：宽 LMUL vs naive 三芯片消融；Win-B：能力调优产品-归约-反量化内核，内核级，vs 真标量 + 指令级核验朴素向量，单板）。登记的 Win 只作"机制在工作"的 sanity，**绝不入 beat 语境**；任何落败/对比结论**反汇编钉死前不得书面引用**。
- **[L-8] 构造语义纪律**：论文与文档中"由机制构造 / mechanically constructed"**仅指强义 constructed**（[K-4] 定义）；弱义必须写作 "descriptor-selected composition"。弱义充强义 = 违宪。

## 2. 目标机制规格（系统该长成什么样）

### 2.1 能力 Schema（决策核）

- **[S-1] 事实模型**：每条事实含 `id`（`rvv.v` / `rvv.zvfh` / `ime.vmadot` / `scalar.zbb` / `uarch.vrgather_slow` …）、`kind ∈ {isa_ext, sub_ext, uarch, policy}`（**闭合枚举**——现状为开放字符串，收口为工作项）、`implies:[id]`、`conflicts:[id]`、`params`（**命名空间化的结构化字段**——现状为隐式字符串键，命名空间化为工作项：`vlen, elen, sew_set, lmul_budget, vreg_count, cacheline, ime.tile(...)…`）、`provenance ∈ {hwprobe, cpuinfo, vendor_table, manual}` 与 `trust ∈ {measured, declared}`（**两字段现完全缺席，新增为工作项**）。
- **[S-2] 关系语义**：加载期计算 **implies 传递闭包**（现查一层，修复与 [X-ZVFH] 同一里程碑验收，[B-7] 已核字节中性）；conflicts 命中即 fail-closed 拒绝；**未知事实 = 假**（缺省拒绝，绝不缺省放行）。
- **[S-3] 探针只写事实**：hwprobe/cpuinfo/厂商表适配器只产出事实条目；任何"探到 X 就走 Y"属违规（重新引入隐藏分支）。
- **[S-4] uarch 作为事实**：粗粒度事实（如核数）驱动决策的机制**已存在**；目标是**每核 quirk 表**（高 LMUL 下 vrgather 慢、段加载收益等，C908/X60 各一张），供 P6 键控；**走表不走 if**。
- **[S-5] schema.def 声明工件（哈希对象，[J-7] 六项清单）**：①事实记录字段与类型（含 provenance/trust 枚举）；②kind 闭合枚举；③关系类型表（implies/conflicts 及语义标注——现状关系为扁平三列表**无类型元数据**，补齐为工作项）；④params 命名空间声明；⑤插件接口签名的可序列化形态（现状为虚接口**非声明式**，反写为工作项）；⑥**路由描述符操作数角色词表**（现状**混合**：N-operand 路已结构化、块点积角色仍是表字符串——统一为工作项）。**不入 shape**：具体事实行、params 取值、插件内部代码、测量库、模式注册表条目。
- **[S-6] 两级门**：**[F-2′] 操作门（逐 PR）**——家族接入 PR 系列 diff ∩ schema.def = ∅；**报告门（逐版本）**——规范化序列化（排序 JSON）→ SHA256 + RFC 版本日志；附加式演进（新增可选字段/新 kind/新关系型）记 minor 并标注 "extension not modification"。论文主张的精确形态："自第二家族接入起，没有任何家族接入曾**要求**修改 shape"（逐 PR 可审计）。
- **[S-7] 非目标**：schema 不内置成本模型；成本住测量库（按 instance-hash 键控），schema 只答"能不能/是什么"。
- **[S-8] 家族语义（Zbb 核查的推广）**：**家族 = 能力声明 + 所有权边界，不是指令密度**。允许"**能力门家族**"——其 owned 内核主体用基础指令，家族事实充当门与可选加速子事实。子事实粒度对称成立：`zvfh` 之于向量家族 ≡ `zbb/zba/zbs` 之于标量家族。由此，广度见证家族正名为 **[X-SCALAR] 标量家族（向量缺席）**，位操作扩展为其子事实/能力门（附A 有旧标签映射）。

### 2.2 插件协议（家族接入唯一通道）

- **[P-1] 接口冻结**：`ExtensionPlugin` 为准 ABI（其可序列化签名入 schema.def ⑤）；改动需 RFC。插件可提供：事实与关系声明、合法性谓词、发射模式（向 [PAT-1] 注册）、lowering 钩子、测试；**不得**改核心目录任何文件。
- **[P-2] 接入五件套**（一个家族 = 一个 PR 系列，缺一不收）：①事实+关系表行；②合法性谓词；③发射模式（或声明复用）；④测试（lit 字节精确 + 每板 objdump golden）；⑤ ledger 条目。
- **[P-3] 接入验收 = falsifier 组全绿**（[F-1..F-6]，独立家族含 F-6）。
- **[P-4] 外部可接入（M4 定义）**：接入文档完整到"非核心作者仅凭文档可完成一次家族接入"——C1 从演示升级为协议的判据。

### 2.3 发射与构造（Track B 目标态）

- **[K-0] 双路承认与收敛**：承认 [B-3] 双发射路径；**终态 = 泛型操作数层成为唯一发射权威**（[K-3b]），平面发射器与分解构造路在其下统一；过渡期两路并存但状态按 [K-4] 六态如实标注。
- **[K-1] Emission Plan 为中心工件**：声明式配方 = 迭代结构 + body 模式引用 + 能力键；可序列化、可 lit。
- **[K-2] Body 模式库**：加宽–点乘–归约、dequant 查表/位解包、repack/blocking、归约树、掩码尾部处理、**[K-2b] 宽钳位/双区 body（widen–clamp–narrow，首个"缺口关闭"模式，关闭后同内核同板复测 vs 自动向量化）**；每模式以 (SEW, LMUL, VLEN 符号量) 参数化；**码本参数化**为专项（现未启动）。
- **[K-3]（基线，带边界）**：N-operand 达成于产品-归约形状族；掩码族排除入边界地图。**[K-3b]（M2）**：泛型操作数层成为唯一发射权威；验收 = 既有三形状 + 掩码族之一经泛型层重发射，字节精确不回退。
- **[K-4] 六态阶梯（全分母内核统一状态机，可自动读出）**：
  `absent → emittable（可发射+转换级单测） → dispatch-wired（生产调度接线，body 手写） → constructed-weak（描述符参数化组装，算术主体为被选择的手写 helper） → constructed（body 由模式库原语构造，强义） → covered（constructed + [K-5] 时效适用项全绿 + 回归架记录在案）`。
  硅封状态（每板 objdump golden）**单列跟踪**，不并入六态。**单体 body 燃减清单**（K-quant / 码本 / fp4 / 三值等）由状态机自动生成，进 CI 报告。
- **[K-5] 正确性门**：整数路径字节精确；浮点路径 ULP 上界声明；VLEN 翻转 lit 矩阵 ≥ {128,256}×{m1,m2,m4}；每板 objdump golden（指令形态 + LMUL 断言）；全部进 CI。
- **[K-6] 缺口关闭环 [GAP-1]**：任何性能落败（或意外持平）必须归档 triage 为四选一——`{缺能力事实 | 缺模式 | 选择错误 | 物理（带宽墙）}`；追因需反汇编证据（[L-7]）；判为缺事实/缺模式者 → 命名新条目进 schema/注册表 → 关闭 → 同内核同板复测 → 归因日志引用缺口 ID。**首个实例 = 钳位回归 → [K-2b]**。此环的档案本身是 C3′ 的叙事素材（负例 → 可归因修复）。

### 2.4 合法性 · 调度 · 归因（fail-closed 双门 + 三级归因）

- **[D-1] 编译期门**：plan 合法 ⇔ 能力谓词在目标 schema 实例（含闭包）下全部可满足；任何未知 ⇒ 拒绝；**该拒绝必须自足**（不依赖调用方兜底）。
- **[D-2a] 装载期最小解析（M1，重构现有）**：现有"编译期物化、调用方一次性提供的能力开关"重构为：消费显式 schema 事实实例 → 计算 **declared-instance-hash** → 落一条解析记录。热路径零逐次检查；**per-dispatch 强制永久禁止**（[NG-3]）。
- **[D-2b] 完整运行期链（M2/M3，增量）**：hwprobe 适配器 → 事实（provenance=hwprobe, trust=measured）→ instance-hash → **[D-3] 调度表按 instance-hash 键控**（同一二进制多板装载不同变体集，核心不变）。
- **[D-4] 三级归因**：
  ① **编译期选择归因（M1 硬门 = 100%）**：JSONL `{kernel, candidates[], keys_evaluated{}, chosen, reason∈{only_feasible, prior, measured}, declared_instance_hash, ts}`——由 [B-5] 富属性重构出口；
  ② **装载期解析记录（M1 硬门 = 每进程 1 条）**；
  ③ **运行期归因（M2+，随 D-2b）**。
  **归因范围扩展（M2 增量）**：调度阶段（为何选此 LMUL）与合法性阶段（为何拒）纳入日志——[B-5] 指出这两段现缺。

### 2.5 选择器（Gearbox 目标态）

- **[SEL-1] 两段式**：`feasible = 合法性过滤(candidates, schema)` →（有测量）memoized argmin →（冷启动）**能力先验排序层**：GEMM 形状 ∧ `ime.present` → 矩阵范式变体；否则寄存器预算内最宽 LMUL；否则默认。先验层独立于成本函数，**不污染成本纯度**。
- **[SEL-2] 硬时序**：先验层必须**先于或同于 P7（矩阵接管 GEMM 形 prefill）落地**——[B-6] 的"两族不竞标"在那一刻失效，先验层从装饰变裁决者。
- **[SEL-3] 测量回填与声明限制**：异步微测 → 测量库（instance-hash + kernel + variant 键控）→ 命中 memoized 路径。无搜索、无成本模型学习；留外部 tuner 插点（文档化即可）。

### 2.6 Falsifier 组（C1 证据标准，全部进 CI）

- **[F-1] 零分支**：`grep -rE <family_regex_manifest> core/` 命中 = 0（白名单仅表格文件）；每家族接入登记其名字/助记符正则；需一个能区分真分支与同名假阳性的判读规程（命中即红，白名单变更走 RFC）。
- **[F-2′] 操作门**：家族接入 PR 系列 diff 不触及 schema.def（全局 shape-hash 保留为版本报告项）。
- **[F-3] 变更收容**：接入 PR 仅触及 `plugins/<family>/` + 表格行 + 文档——**前提 = 家族代码目录归拢**（M1 结构性前置，趁重构窗口做）。
- **[F-4] 归因完备**：按 [D-4] 分级——M1 查①②，M2+ 查③。
- **[F-5] fail-closed 模糊测试**：随机删除/伪造事实实例下，非法 plan 全部被拒（非误编译/误发射）；向量缺席实例复用为 [F-6]/[X-SCALAR] 测试资产。
- **[F-6] 独立性判据**：声称 independent 的家族，其全部变体能力谓词 implies 闭包 ∩ {rvv.*} = ∅（脚本化）；且存在向量缺席实例使其变体 `only_feasible` 并被真实选中。

### 2.7 成本 Ledger（C2 自动化）

- **[LED-1]**：每家族 `{family, code_LOC(cloc, 不含测试), test_LOC(单列), table_rows, interface_touchpoints, calendar_days}`，脚本从 git 历史自动生成，进 CI 报告；首家族数字（≈2484 行）必须可复算。
- **[LED-2] 边际成本曲线**：家族 ≥3 自动出图（LOC vs 家族序号）——C2 从数字到规律的升级件；**依赖 [X-SCALAR] 落地**。
- **[LED-3] 对照锚**：定性锚 = Cambrian（六平台六套手写 kernel+packing，K1 需手写汇编）；量化砖 = ggml 仓库按家族分支代码量/churn 统计（遗留行动项）。

### 2.8 模式注册表（C3′ 一等对象）

- **[PAT-1] 注册表为数据**：每条 `{pattern_id, requires(能力谓词), transform(指向 pass/plan 变换), mechanism(为什么快，一句), metrics_hook, status ∈ {mechanized, partial, planned}}`。基线：收缩/产品-归约族**已数据化**；目标：推广为统一注册表并把块量化 body 数据化。
- **[PAT-2] 初始条目**：P1 宽 LMUL 分组；P2 加宽–点乘–归约；**P2b 宽钳位/双区**；P3 寄存器驻留；P4 布局/repack；P5 精度路径（zvfh/bf16）；P6 微结构规避（uarch 表键控）；P7 矩阵范式接管（`ime ∧ shape`）；P8 向量位操作辅助解包（zvbb，削 dequant 指令数）。
- **[PAT-3] 迁移性判据（进 CI）**：同一注册表在双板（VLEN128/VLEN256）**零条目改写、仅键值不同**即通过（diff 注册表 = 0）。

## 3. 覆盖率与成熟度（"真正的 compiler"怎么量化）
