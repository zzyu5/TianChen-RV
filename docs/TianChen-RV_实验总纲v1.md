## §1 实验宪法(八条全局纪律 —— 采纳草案 §2,补双层键)

把教训编进结构,而非靠人自觉:

1. **格 schema 二分**:测量格 `{值, 单位, 状态∈{measured|stale|board-pending|open|n_a}, 环境指纹, 快照, 工件指针, 对手指针, 配对会话}`;结构证明格 `{判定 pass/fail, CI 日志, 快照}`。**`open`(原 presumed)永不可被正文引用**;指纹任一分量变 → 同指纹格自动 `stale`;跨会话不比。
2. **环境指纹 + 配对测量**:指纹 = hash{板/SoC、CPU、内核、libc、双方编译器与旗标、**ggml 版本与构建开关(含 repack)**、线程/亲和、governor、内存}。SOP:固频 + 钉核 + 丢预热 + **我方/对手同会话 A/B 交替** + N≥10 中位数+IQR + 降频守卫(触发作废)。
3. **T-N 噪声地板(一切效应判定的地基)**:每板×每基准类跑重测-重测得运行间 IQR%;**任何 Δ 须 |Δ|>2×噪声地板 且 bootstrap 95%CI 不含 0**;无 T-N = 无判定资格。
4. **对手解析探针**:在钉死的 ggml 版本 + 该板默认构建下,探测每个 `(算子,格式,形状类)` **实际派发的 kernel**,产映射工件。对手类 = `{出厂派发(唯一贡献/beat 基线) | 同算法(诊断) | naive-RVV(sanity) | scalar-oracle(sanity)}`;**vs-framework 测量格无探针工件 = CI 判 INVALID**(解决"routing 随板/格式/版本变、手填必腐烂")。
5. **传导会计(micro→e2e Amdahl 四列)**:`相内时间占比% → Amdahl 预测相级Δ → 实测相级Δ → 传导效率`;核级赢无传导列不得写"传导到 e2e";**带宽受限内核以 parity 为零假设**(parity 是物理确认,不是失败)。
6. **provenance 清单(强/弱义机检 + [L-8] 执法)**:每个机制构造的 body 发射时写出其**模式原语 ID 列表**;强义 constructed = 清单存在 ∧ 无不透明手写 helper;弱义 constructed-weak = 描述符选择的手写片段。**六态从此脚本可判、不可辩解**(这是执行总纲里"[L-8] 现为 prose 纪律"的执法工具)。
7. **快照/纪元**:分母清单 = 版本化工件(钉 ggml 版本);上游新增格式 → 开新纪元、曲线断点标注;一切导出携 `{repo 快照, ggml 版本, 纪元}`。
8. **oracle 结构无关**:标量 oracle 不与任何向量参考共享 bit→lane 解码 + 性质测试(全零/交替符号/满幅/fp16 次正规极端指数)+ 变异测试;oracle 入库有版本。

**双层行键(采纳草案 §1 尾,替代先前的四元键):**
- **分母键(覆盖率口径)** = `(算子, 格式[, 形状类])`,每对只计一次,覆盖态 = 其全部变体行的最佳六态(防多路径重复计数虚增)。
- **测量行键(性能口径)** = `(算子, 格式, 路径, arity, 形状类)` + 变体 ID + 选中方式∈{mechanism-selected, forced};**产品级主张只引 mechanism-selected 行,forced 行只用于消融科学**。
- **形状类**必入键:`{decode-GEMV(M=1), prefill-GEMM(M 扫描), micro-fixed}`——micro↛e2e 与 IME 交叉点实验的载体。

## §3 IME 实验的 grounding(对草案 §4 的批判性修正 —— 本纲最重要一节)

草案的 IME 双轨设计**思想正确**(轨1 结构佐证 / 轨2 性能),尤其轨2"把比较关进同一系统内部、唯一自由度=内层 tile 范式"是**净范式贡献的最干净定义**,厂商换族 confound 从设计上消失。**但可行性必须摆正:**

- **轨 1 —— C1/N2 佐证(承诺交付,现状可达):** 6 个 leaf MAC 硅上逐位 16/16 + tiled-matmul 边界 op 正确性 + 零分支 + 插件收容 + 双板 objdump。这是 IME 的**确定性交付**,证"矩阵范式骑同一条能力 pipeline + 硅上正确"。**T5a 里"自有整 tile GEMM 字节精确"一格是轨2 的、当前为空(aspirational),不要当已有。**

- **轨 2 —— 自有机制构造的 IME GEMM + 2×2×M 范式消融(理想 / gated / M3+):** 这是 T5b/T5c 与 §4.2 干净消融的**前提**——但**我们现在只生成单条 leaf MAC、根本没有自有 GEMM**。构造一个 tiled、int32 累加器跨 K 寄存器驻留、带 dequant/blocking 的 IME GEMM,是**重活,难度 ≥ block-dot body 强义构造**。**修正草案 §8.4**:"自有 GEMM 与 [K-3b] 无关、可与 body 燃减并行轻启"**不成立**——它 IS 一个大构造任务,应排 M3+,且很可能与 body 模式库([K-2])共用原语与机制。
  - **默认姿态 = 草案 §4.6 的回退,而非例外**:轨1 独立成立;P7/prefill 净范式贡献标 `open`;T5b 留空模板入库;**回退不改任何已发表主张**(解耦写进设计)。
  - **T5b 的 2×2 可能坍缩**:IME 共用向量寄存器堆、需矩阵优 tile 布局,"IME@向量优布局"多半 N/A;实际是 {RVV@向量优, RVV@矩阵优, IME@矩阵优} 三格 + M 扫描,草案的 N/A 处理适用。

- **T5d 厂商路径(采纳,降级为方法学对照):** 厂商 IME 家族级 e2e 只作外部参考 + M=1 对照(增益不塌回 1.0 = 换族 confound 的实证)→ **这是现状唯一能报的 IME e2e**,诚实定位 = 家族级、**不可归因于矩阵单元**;进论文方法学讨论,不进贡献。M=1 对照从"尴尬"升格为"方法学发现"这一手采纳。

- **净结论(IME 现在钉死什么):** 轨1(结构 + 硅上正确)+ T5d(方法学)= 现状确定性证据;轨2(自有 GEMM + 净范式消融 + 交叉点 M* 回写选择器)= pre-declared 的 M3+ 理想扩展。**IME 表的职责是 C1/N2 佐证,不是性能头条**——这与执行总纲的现状(IME e2e MEASURED-NULL / 不可隔离)一致。

## §4 消融目录(采纳草案 §5 + grounding)

> **Win 登记阶梯([L-7] 定案,与对手类一一对应):Win-A**(能力形状旋钮 vs naive)/ **Win-S**(两轴 vs 标量+朴素;*即历史误标 "Win-B" 的条目,改名归 sanity,登记簿留 alias 注记*)= **sanity**;**Win-B**(算法/布局 vs 框架自家 kernel)= **kernel 级贡献**,**B1/B2 下标由对手探针定 = 该板出厂路径**(出厂走 repack 的板上打赢其 block-dot ≠ Win-B,只是 algorithm-matched 诊断、不入登记簿);**Win-C**(相级 e2e 过 [PERF-1] 八门 vs 出厂 ggml)= **相级贡献**。A/S/B 绝不入 beat 语境。

1. **Win-A(能力形状)**:同 kernel/板/会话,旋钮 narrow↔wide 配对;**前置 = 双板候选集哈希相等**;跨板翻转主张 = (A 选窄 ∧ B 选宽) ∧ 双板归因日志 reason 在案。**身份 = sanity,永不入贡献列。**
2. **选择器四配置**(常量/仅先验/仅记忆/先验+记忆)× oracle 遗憾度;专项复现并消灭"矩阵静默落败"。**gated on 先验层(M3)。**
3. **模式逐条 on/off**(T3p):每条模式的机理声明获得数据判决。**gated on 模式注册表。**
4. **能力事实伪造**:同 kernel 构造 {事实全集, 删一事实, 删闭包中间层} 三实例,观察合法集收缩与选择迁移——"schema 是唯一决策源"的行为学证据。**现状可建(轻),建议 M1 纳入**(它同时喂 T1b)。
5. **传导消融**:对已证 micro 赢的 kernel 做 Amdahl 四列。

## §6 执行顺序与硬依赖(采纳草案 §8 + 两处修正)

1. **T-N 与探针先于一切效应判定**(无地板无对手 = 无资格)。
2. **provenance 清单先于六态自动化**(否则 T0 靠人判 + [L-8] 无执法)。
3. **先验层([SEL-1])先于 P7 与 T4b/T5c**([SEL-2] 硬时序:P7 落地瞬间两族竞标,常量分会让矩阵范式静默落败)。
4. **⚠ 修正草案 §8.4:自有 IME GEMM(§3 轨2)不是轻活、不与 body 构造无关**——它是 M3+ 大构造任务,很可能与 [K-2] body 模式库共用原语;不排进 M1/M2 前置,不阻塞轨1。
5. **板 C 仅在 T1b 的 conflicts 见证行需要时一次性租用**(RVV0.7.1,永不进性能表)。
6. **工具即证据线**:实验前置工具(T-N/对手探针/provenance 清单/归因 JSONL/schema.def/ledger 脚本/coverage 脚本)= 执行总纲 §10 TOP-10 的证据线动作 —— **一次建设、两处收益**(解锁实验 + 关闭 C1/C_attr/C2 的机检缺口)。
