# 正确性与证书

1. **[K-5] 正确性门**：整数路径字节精确；浮点路径 ULP 上界声明；VLEN 翻转 lit 矩阵 ≥ {128, 256} × {m1, m2, m4}；每板 objdump golden（指令形态 + LMUL 断言）；全部进 CI。
2. **[K-5b] 证书三要件**（进 CI，缺一即 cert 无效）：
   1. **语料完备**——每个算术项被非退化 exercise（dmin≠0、满幅 scale、交替符号、次正规）；恒零 / 恒单一符号语料 = 该项从未通电。
   2. **输入路径同源**——oracle 与被测 dispatch 逐环同源；cert 必须声明输入路径谱系（用 row-quant oracle 验 mat-quant dispatch 是致命坑）。
   3. **oracle 独立**——不与被测物共享读取 / 解码实现（**空心证书禁令**：共享实现会让同错互相抵消）。

   旧 cert 按三要件补标注，缺项降级 partial。
3. **[K-5c] ZERO-MODEL 终审法**：正确性争议不靠"kernel vs 某 oracle"多轮互搏（oracle 本身可能选错）。终审 = 捕获真实 dispatch 输入 → 用被测系统自身原语从该输入**零复用重算** → 与 kernel 中间值逐位对。争议默认走 ZERO-MODEL → 独立实现对位终审两步。**单证书永不定案；定罪与翻案同等严谨。**
4. **对拍（一步三验）**：我方 vs oracle、对手 vs oracle 各对一次答案，同时完成——我方没算错、对手没算错、对手就是真实派发的那一个。任一失败 → **不计时**，落对应 VOID（我方错 / 对手废 / 派发不符）。顺手自动记录我方产物真实向量运算指令数（配置指令与死值不计）入行——"仪式向量化"自动现形，**记录不拦截**。
5. **oracle 结构无关**：标量 oracle 不与任何向量参考共享 bit→lane 解码；性质测试（全零 / 交替符号 / 满幅 / fp16 次正规极端指数）+ 变异测试；oracle 入库有版本。
6. **空心门禁令**：**空心门比没有门更坏**。任何检查必须有**负控证明其能变红**；变不了红的检查判死并清除。新增检查的唯一途径 = 提案入 [issues](../issues/index.md) → 用户裁 → spec 版本化更新。**禁为过门而豁免 / 删检查 / 改判据**——红是真状态，禁把红说成绿，禁以"未进 CI"当作缺陷不存在。**白名单只减不增**（把真缺陷变"已知例外" = 滑坡）。
7. **"X 不存在"类断言禁用 `head` / 固定窗口命令作依据**；须用精确谓词或抽到语法边界的机核。**展示可截断，判断不许。**
8. **探针须双法交叉验证**：单一 grep 形态可静默退化，且退化方向恰好产生看似合理的小数字，不交叉验证抓不出。〔本条入 canon 的**归属节点**待裁，见 [待裁](./待裁.md)；规则本身现行有效〕
9. **硬件证据通用契约（一条，覆盖全部算子族——禁逐族另抄一份）**：当某条 route 主张"真的在硬件上跑 / 正确 / 快"时，证据必须包含：
   - 被测 **artifact 身份**（生成它的 selected variant / route）；
   - **相同命名的 `ssh` target/profile**（[核心不变量](./核心不变量.md) I8）；
   - **先正确性、后计时**：与可信 oracle（scalar 参考或外部基线）对比的正确性结果；
   - **原始 stdout 或 evidence JSON，且其中真的含**正确性与（若主张性能）计时字段。

   **性能对比证据的更高门槛**（在上列之上另需）：基线实现身份与版本 / 路径；生成 artifact 身份；两侧同一命名 target/profile；compile flags、输入尺寸、数据初始化、warmup / 重复策略、计时方法；计时前的正确性检查；同时含正确性与计时的原始输出或 JSON。（这些要件的执法形态住 [测量判据](./测量判据.md)：环境指纹 + SOP §二.6、构建保真三重 §二.8、部署身份五验 [L-10]；本条只钉"什么算硬件证据"。）

   > **负面清单（都不是性能证据，不得描述成框架 parity 或"成熟"）**：artifact ABI closeout · generated-bundle dry-run · 本地 compile-only · 单个 success marker。〔与 [成色与措辞](./成色与措辞.md) [L-6]③ export-lit ≠ silicon-sealed 同源：那是原则，本清单是其点名形态。〕
10. **断言来源区分**：测试断言要分清来源 —— `HARNESS` 前缀读的是**生成的 C harness 源**（断言函数调用、表达式、prototype、`printf` 格式串等**源级事实**）；`pattern=1 ok ...` 这类**运行期**行**只能**对真远端输出、或确实含 stdout 的 evidence JSON 断言。（[L-8] provenance 清单是被发射的可测工件，其断言按本条的来源区分执行。）

> regime 结构判据（拆 decode / prefill 双 cell）住 [账目与分母](./账目与分母.md)。
