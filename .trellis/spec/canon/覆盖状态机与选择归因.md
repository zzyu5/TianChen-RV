# 覆盖状态机、模式库与选择归因

## 一、覆盖状态机与模式库

1. **[K-4] 六态阶梯**（全分母内核统一状态机，可自动读出，**单调递进**）：

   `absent → emittable → dispatch-wired → constructed-weak → constructed → covered`

   - **absent**：无任何路径。
   - **emittable**：可发射 + 有转换级单测。
   - **dispatch-wired**：生产调度已接线，但 body 仍手写。
   - **constructed-weak**：描述符参数化组装，算术主体为**被选择的手写 helper**（弱义，[L-8]）。
   - **constructed**：body 由模式库原语构造（**强义**，[L-8]）。
   - **covered**：constructed + [K-5] 适用项全绿 + 回归架记录在案。
   - **硅封状态**（每板 objdump golden）**单列跟踪，不并入六态**。
   - 态位的**具体计数、燃减清单、CI 报告机制不属 spec**——只有这台状态机的定义是契约。
2. **[PAT-1] 模式注册表为数据（非散文）**：每条 `{pattern_id, requires(能力谓词), transform, mechanism(为什么快，一句), metrics_hook, status}`。
3. **[PAT-3] 迁移性判据**（进 CI）：同一注册表在双板**零条目改写、仅键值不同**即通过。〔判据的**可执行形态**待裁，见 [待裁](./待裁.md)；判据陈述本身现行有效〕

## 二、选择与归因

4. **[SEL-1] 选择器两段式**：`feasible = 合法性过滤(candidates, schema)` →（有测量）memoized argmin →（冷启动）**能力先验排序层**：GEMM 形状 ∧ 矩阵扩展在场 → 矩阵范式变体；否则寄存器预算内最宽 LMUL；否则默认。**先验层独立于成本函数，不污染成本纯度。**
5. **[SEL-2] 硬时序**：先验层必须**先于或同于**"矩阵范式接管 GEMM 形 prefill"落地。该范式接管落地瞬间，向量 / 矩阵两族开始为同一内核竞标，常量冷启动分会让矩阵范式静默落败——先验层在那一刻从装饰变裁决者。
6. **[SEL-3] 测量记忆层**：异步 / 离线微测 → 测量库 → 命中 memoized 路径。**记录键 = 复合主键** `(declared_instance_hash〔蕴含 march / vlen / vreg〕, kernel, variant, op, engine, regime)`。铁线：**无搜索、无成本模型学习、不对标外部 tuner**（仅留插点文档）；**byte-exact 门 fail-closed**。`selection_valid_input` 采**配对变体严格语义**——仅配对 A/B 的行为 true，单点 vs-opponent seed 一律 false。
7. **[D-4] 三级归因 + reason 主键**：
   - ① **编译期选择归因**（硬门 = 100%）JSONL `{kernel, candidates[], keys_evaluated{}, chosen, reason, declared_instance_hash, ts}`。
   - `reason ∈ {only_feasible, static_order, prior, measured}` 是**所有归因分析的主键**——能力键控与否须做在主键上，**不做在脚注守卫字段**。`only_feasible` = 合法性过滤后仅剩一个候选（能力键 N/A）；`static_order` = **能力盲**的冷启动排序（非能力派生）；`prior` = 严格保留给能力派生的先验；`measured` = 命中 memoized 实测赢家。
   - "是否由能力键选中"直接从 reason 推导（`static_order` → 否 / `prior`|`measured` → 是 / `only_feasible` → N/A）。`static_order` 出现数在先验层落地后应归零；**不归零即先验层覆盖缺口**（自动成为诊断 / 燃减信号）。
   - ② **装载期解析记录**（硬门 = 每进程 1 条）。
   - ③ **运行期归因**。
   - 归因范围含调度阶段（为何选此 LMUL）与合法性阶段（为何拒）。

> 覆盖率四指标（`C_dispatch` / `C_construct` / `C_construct+` / `C_attr`）住 [账目与分母](./账目与分母.md) [COV-2]；强/弱义之别住 [部署与构造语义](./部署与构造语义.md) [L-8]；"运行期归因"的措辞两层拆分（现系统事实 = 编译期 fail-closed）同址。
