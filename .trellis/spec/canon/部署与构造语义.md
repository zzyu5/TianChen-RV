# 部署与构造语义

## 一、部署的 ≠ 证过的

1. **[L-10] 部署身份纪律**：任何 e2e / seal 主张必须核验**实际部署物五验** = 符号 / 反汇编形态 / vl · VLEN 形态 / forward banner / 编译器身份。**出货形态 = clang 独立 .o 经对象导出正门链接**；禁止把 emitted C 注入对手构建链、由其系统编译器重编后仍称"部署了已验证 kernel"。须设"**不加载我方 object 即失败**"的反向控制。
2. **[K-8] 发射权威机检 [F-EMIT]**（进 CI）：生产 dispatch 路径上的每个构造格必须携带 front-door provenance；检测到绕过 L2 typed-region 的直连发射路径**被生产选择器选中** = 红。过渡期旁路格白名单化（带退役批次号），**白名单只减不增**。终态 = 旁路清零。
3. **[K-9] 退役可复原闸**：任何 kernel / 发射路径的退役必须 ① git 历史可查 ② 登记四要件（格名 / 退役依据 / 替代路径 / 复原指针）。CI 校验"一切已退役格 ⊆ 自动生成的 RETIRED-INDEX 且四要件非空"——**无登记的删除 = 违规**。

## 二、构造语义（强义 / 弱义）

4. **[L-8] 弱/强义构造纪律**："由机制构造 / mechanically constructed"**仅指强义 constructed**（[K-4] 定义）：body 由模式库原语构造。**弱义**（descriptor-selected：算术主体是被选择的手写 helper）必须写作 `descriptor-selected composition` / `constructed-weak`，**绝不冒充强义**。强弱不靠自觉——由 provenance 清单机检（发射时写出模式原语 ID 列表：清单存在 ∧ 无不透明手写 helper ⇒ 强义）。**弱义充强义 = 违宪。**

## 三、[K-10] 结构级 / 参数级判据

5. **判据**：一个变体差异若改变 **{迭代空间拓扑 | 数据 / 布局消费契约 | 优化目标（算力吃满 vs 字节最少）}** 之**任一** → **结构级** = 独立 **Emission Plan**（独立 L2 typed region · 独立 provenance · 独立证书 · 独立 roster 行）。仅在**固定结构内**调宽窄（VLEN / LMUL / tile 尺寸 / 展开因子 / lane-width）→ **参数级** = 能力键（[SEL-1] 键控 · 不新增 plan）。
6. **硬禁**：**结构级差异禁实现为 plan 内旋钮**——knob 拧不出结构。
7. **结构级判例**：**GEMM 与 GEMV 判定为结构级**（三问全变：迭代空间拓扑 M×N×K ↔ 1×N×K · 数据消费契约 权重复用 ↔ 零复用 · 优化目标 算力吃满 ↔ 字节最少）。外部佐证 = 上游 linalg.matmul / linalg.matvec 分立 named op；内部佐证 = [COV-1] 分母 vec_dot 行与 GEMM tile 行分立。
8. **选择层职责**：selector 在 **plan 集内**按 **{形状事实 ∧ 能力事实}** 选择；归因日志照 [D-4]；**M\* 为实测标定事实写回 schema，禁 `if(M==1)` 硬编码**。
9. **反向确认（禁翻案 sealed 杠杆）**：VLEN / LMUL / tile 宽 / 展开因子 / lane-width 经三问复核 = **参数级**（能力键 · 归类正确）。**已 sealed 的参数级杠杆禁借 [K-10] 审计翻案。**
10. **术语精确化**：**"发射器不成熟"表述禁模糊总称**，必落到 {缺 plan（哪个）| 参数未键控（哪个键）} 二选一。"发射器成熟度" = **plan 库覆盖度 + 参数键控落地度** 两个可数维度。

## 四、[DISCRIMINATOR-OPPONENT-BOUND-TYPE] 传导判别律

11. kernel 算力赢传导到 e2e ⟺ **对手 compute-bound**；washes ⟺ 对手 memory-bound。判别键 = **对手的 bound-type**（由 相 × 板 × 出货编译器对该 kernel 计算路的 autovec 质量共定），**非格式名、非 kernel 倍数大小**；与编译器轴正交。用法 = **前瞻化**：开测前预注册对手 bound-type 判定与传导预测，收口统计预测命中率成表。它是"何时传导"的判别律，**不是新性能主张，不新增绿格**。

## 五、[MOD-COST] 插件模块化的双 regime 成本分解

12. 轨一 **integrated 子扩展** = <100（复用宿主发射机器，边际近零）；轨二 **independent family** = 如实报 pin-verified 实测（[F-6] 独立性禁复用宿主 emitter → 付净新 emitter 成本），**成本高即论点本身，非缺陷、非超标**。ledger 须 `--at-commit` 可复算。该规律是 **C1 模板可复用性/模块化的证据**，不再定义贡献 C2；C2 的正本是公式中心的 construct–legalize–select 系统。

## 六、能力措辞两层拆分

13. 现系统事实 = "编译期 VariantSelection fail-closed"；"load-time hwprobe / 运行期归因"一律降为【目标契约·未实现】展望条目并显式标注。**禁未标注混写。**
