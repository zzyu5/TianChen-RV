# 非目标（越界即标记）

1. **[NG-1]** 不做通用搜索式或在线自动调优。允许 qualified offline measurement 在有限合法候选中定档；它不是 compute authority。
2. **[NG-2]** 不做完整图级 / 端到端模型框架——输入侧止于图级处理后的 operator problem 或小型 fused region；source IR 可以语义充分，但不得预先包含 family schedule。
3. **[NG-3]** 不做 per-dispatch 强制检查 → 全文住 [能力模型与插件协议](./能力模型与插件协议.md) [NG-3]。
4. **[NG-4]** [PERF-1] 全绿前不出现任何 beat 措辞 → 全文住 [成色与措辞](./成色与措辞.md) [NG-4]。
5. **[NG-5]** 不为接扩展而接扩展（先过 [X-0] 三问，见 [缺口与认输](./缺口与认输.md)）。
6. **[NG-6]** v1 不追求 upstream LLVM / MLIR 合入。
7. **[NG-7]** 不投资"适配对手编译器后端"——我方出货形态 = 自有 clang .o 正门；**对手 shipped 编译器的 codegen 质量是生态事实，不是我方优化对象**。
8. **[NG-8]** 不以投稿冻结、表格补齐或 presentation deadline 反向决定架构。理想论文问题可以指导长期方向，但具体改动仍需同时推进真实系统能力、正确性或性能。
9. **[NG-9]** 不把 GPU 当作现有 EmitC emitter、外部 kernel 名登记或 RVV body 的另一种发射目的地；GPU 必须在 artifact-neutral construction 重构完成后作为完整 family 接入。
10. **[NG-10]** 当前不做 CPU/GPU 跨设备 runtime selector；缺 transfer、observer、共存 artifact、dispatch cost 与真实 workload 时，target/profile 在编译前绑定 family。
