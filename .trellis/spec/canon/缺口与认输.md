# 缺口、认输与杠杆

1. **[K-6]/[GAP-1] 缺口关闭环**：任何性能落败（或意外持平）必须归档 triage 为 {缺能力事实 | 缺模式 | 选择错误 | 物理（带宽墙）| 未接线（emitted kernel 未被推理框架 forward 消费）| 部署身份错误 | 编译器不对称}；追因需反汇编 / 计数器证据。判为缺事实 / 缺模式者 → 命名新条目进 schema / 注册表 → 关闭 → 同内核同板复测 → 归因日志引用缺口 ID。**"未接线"是 e2e 稀释头号原因，不得与"物理"混判。**
2. **认输门槛**："**解剖了 · 学了 · 造了等价能力 · 仍差在具名的 X**"方可具名-X。"对手强 / 物理墙 / 尽力了"一律不构成出口；**物理借口同板一律无效**。不达格必走完整攻坚环（解剖 → 构造 → 前门 → G1 byte-exact → G2 cold）后方可具名-X，且带逐指令墙证据 + 三档墙分类。**零未攻认输。**
3. **[K-7] 首次发射律**：首次发射的 kernel 功能正确但性能不成熟是常态；其成熟杠杆可具名、可由能力事实键控、可族级复制。推论：**性能覆盖面可按批提升而非逐格硬凿**——每把杠杆都是族级 / 范式级。
4. **[X-0] 接入三问**（任何扩展先过再动手）：
   1. **服务哪条贡献？答不出 = 不做**
   2. 有无负载价值或曲线价值？
   3. 成本进 ledger 且预算被接受？

> 三档墙分类词表（{指令数内禀 | 内存墙 roofline | 对手结构优势具名}）与物理墙收严规则住 [对手与档位](./对手与档位.md) §三；[K-10] 结构级 / 参数级判据与 [C2-1] 双 regime 成本住 [部署与构造语义](./部署与构造语义.md)。
