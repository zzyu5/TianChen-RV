# 对手与档位

## 一、判档

1. **对手三档法**：每行对手必判 **{手调 | 通用向量 | 标量类 | UNRESOLVED}**。
   - **手调** = 为具体芯片优化过（hand-brick repack、vl 特化手调 vec_dot、符号带 `_vlNNN` / `_16x1` / `_8x8`）；
   - **通用向量** = 人写向量 intrinsic 但未按芯片调（block-dot、native-vec、手写非特化 `__riscv_v_intrinsic`）；
   - **标量类** = 标量源码对手，**含编译器 autovec**、出厂标量派发、generic-C、f16-LUT。
   - 判定**必须符号级证据**（对手符号名 + objdump 计数 + 源码归属）；判不清标 **UNRESOLVED 单列，禁猜**。
2. **对手 = 该板 ggml 实际部署派发的函数**，以部署事实证成（反汇编 dispatch / 类型注册表）。**可得性不构成资格**。同一谓词全表同一政策。
3. **对手类机判**：对手身份 = 探针解析出的具体 kernel 符号；对手类由符号映射表机判，**禁手写档位类目**。
4. **同一格式的不同核（不同 vl / md5）分立记账**；禁把一个核的证伪外推到另一个核。
5. **对手数值错误 → 成绩作废登记**，降落该板下一条真实派发路径；**禁用坏对手的时间算倍率**。
6. **对手家族探针**：每个对手**家族**做一次性身份探针 + 故障注入对照（证 oracle 有牙）——按家族一次，不按格重复。
7. **UNRESOLVED 清偿**：UNRESOLVED = 临时取证标签，**非常设档位**，禁跨战役过夜；清零后从头条删。
8. **VOID 三出口限期清偿** {重测 | 降档对局 | 环后具名}，禁躺平。
9. **架构不可达上报例外**：某板某格**结构上不存在合法对手**（硬件数据通路装不下该格式）时，措辞锁定为"该板该格结构上不存在合法对手 + 厂商源行级指针"——非我方未完成、非厂商疏漏。分母 / N/A-hw 零改；**禁以此格未 PASS 计作我方失败，亦禁以此格计作我方胜利**。

### 对手类词表（**角色** · 闭合枚举 · 与上方三档法**正交**）

三档（§一.1）判对手**强度**；本词表判对手**角色**——即**哪一类对手可以计 beat**。**本节是该词表的权威声明**，别处（[evidence](../evidence/index.md)、[测量判据](./测量判据.md) §六 T-X 列 5）按引用对齐、**不重列**：

- **factory-dispatched** —— 框架在该 `(板, 格式, 形状类)` 上**实际派发**的出厂 kernel；**唯一贡献/beat 基线**，只有它计 beat。
- **algorithm-matched** —— 同算法/同布局对照，仅作诊断（"布局/算法是否有帮助"）。
- **naive-RVV** —— 朴素向量对照，仅 sanity。
- **scalar-oracle** —— 标量对照，仅 sanity；**scalar 永不作贡献基线**（vector-vs-scalar 只测"我们向量化了"，MLIR/autovectorization 已提供，[成色与措辞](./成色与措辞.md) [L-6] vs-naive ≠ vs-framework）。

> **★术语碰撞（如实登记 · 不自裁）**：「**对手类**」一词在本文件**同时指两个不同的闭合枚举** —— §一.3 的「对手类」= **档位类目**（三档法 {手调 | 通用向量 | 标量类 | UNRESOLVED}，由符号映射表机判）；本节的「对手类」= **角色词表**（factory-dispatched / algorithm-matched / naive-RVV / scalar-oracle）。两者语义正交、互不替代，却**共用同一术语**。命名归属 = canon 级 → 条目见 `ISSUE-088`（[issues](../issues/index.md)）。**保守默认 = 两枚举并存、引用时须显式限定是「档位」还是「角色」**；**禁 agent 自行改名或合并**。

## 二、编译器身份

10. **[CASE-COMPILER-ASYMMETRY] 判别键**：板出货编译器身份是一等测量维度。**kernel-axis vs-opponent 数字仅在编译器对称时有效**；不对称数字（我方 clang vs 对手 shipped gcc）一律撤回，或归系统账并列出最强基线。
11. **单世界 clang-18**：双板统一 clang-18 对称域 = 主表 headline 唯一口径，一个版本一张表、零逐格口径特例。gcc 视为不存在（仅历史素材与链接运行库）；gcc 数字归档为部署附注，不参与主表胜负、不出现在 recon 输出 / TIER / 头条。本地非部署编译器仅限不碰代码生成的辅助，**二进制级数字零证据地位**。〔与实验总纲的 clang 版本条文冲突，见 [待裁](./待裁.md)〕

> 双账本（kernel 账 / 系统账）的红线全文住 [测量判据](./测量判据.md) [L-9]。

## 三、档位成色（与判档同源，故住本文件）

12. **头条三口径 + 便宜档禁称硬赢**：硬仗（手调）/ 向量仗（通用向量）/ 标量仗（标量类）/ UNRESOLVED 四档穷尽互斥，分报 PASS / 全档量。**便宜档大倍数禁称硬赢**。赢 autovec / scalar-ref / 未优化对手 = 便宜档，须强制标注 `compiler-artifact` 或 `opp-immaturity` 成色注，**禁外推为 win**。
13. **计数≠强赢**：绿格计数增加 ≠ 成色质变。成色质变 = **硬碰硬赢手调对手成排**；赢弱对手 / tie / cross-op / near-parity 一律不计成色，**须与计数分开报**。
14. **输赢同权**：输局桶必填，墙分类三档穷尽 {指令数内禀 | 内存墙 roofline | 对手结构优势具名}，**禁词表外标签**。
15. **物理墙收严**：物理墙 / 内存墙 ⟺ 真 roofline 下**双方同贴同一墙**（≈parity）才许标。单侧 at-wall（仅我方贴墙、对手未贴），或对手换数值档 / 换编译档 = **不许标物理墙**，应标 pending 或"对手结构优势具名"。

> 无限定 beat 措辞的总禁令住 [成色与措辞](./成色与措辞.md) [L-1]/[NG-4]；认输门槛住 [缺口与认输](./缺口与认输.md)。
