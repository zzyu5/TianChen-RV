# Governance Specs

本层回答：**做什么、按什么权限做、停不停、怎么报、文档放哪、怎么判断该不该做**。

不含技术判据——测量法见 [measurement](../measurement/index.md)，已定法条与硬冻结四类见 [canon](../canon/index.md)，架构定法与不变量见 [architecture](../architecture/index.md)，贡献→证据指针见 [evidence](../evidence/index.md)，问题与待裁登记见 [issues](../issues/index.md)。

> **版本**：v7
> **修改途径**：本层版本化，**修改唯一途径 = 用户裁决**；agent 可提案（入 [issues](../issues/index.md)），不可自改。
> 稳定性条款本体（禁热改流水线 / 禁临时加门 / 禁战役中途换判据）见 [measurement](../measurement/index.md) §3.0 哲学与稳定性条款，本层不重抄。

## Pre-Development Checklist（判断提示，不是 gate）

- [ ] 这件事属权限卡四类的哪一类——自决直行 / 必问 / 禁停 / 灰区？（[决策权限卡](./决策权限卡.md)）
- [ ] 若判为「必问」：已**登记 + 采保守默认 + 续推**了吗？还是打算停下等？（停下 = 违例，见 [决策权限卡](./决策权限卡.md#二延后裁决制)）
- [ ] 我是不是在把一件自决直行的事包装成选择题回门？（转嫁决策 ≠ 谨慎）
- [ ] 这一步推进的是哪条贡献主张？答不上来就别做。（[思维准则](./思维准则.md#一主干纪律)）
- [ ] 本轮有文件写入 / 多轮计划 / 研究吗？→ 必须挂任务。（[trellis 卫生](./trellis卫生.md#三一切测量施工必须挂任务且预注册范围)）
- [ ] 要写的规则在别处已有住址吗？→ 链接，不重抄。（[GOV-1] 单一权威，见 [治理通则](./治理通则.md)）
- [ ] 我引用的数字带快照 ID / run-id 吗？还是手抄的？（[GOV-3]，见 [治理通则](./治理通则.md)）
- [ ] 我要断言「X 不存在」吗？→ 禁用 `head` / `grep -A<N>` 类有界窗口命令作依据。（[治理通则](./治理通则.md#七断言纪律治理侧效力)）
- [ ] 触碰集与在飞的其他线相交吗？不相交就并行。（[GOV-7]，见 [队列与简报](./队列与简报.md#三并行纪律-gov-7)）

## 新 agent 上岗顺序

1. **[决策权限卡](./决策权限卡.md)** —— 先知道自己能做什么、什么时候**不许停**。
2. **[队列与简报](./队列与简报.md)** —— 读队列快照，找到当前坐标与队首。
3. **[思维准则](./思维准则.md#一主干纪律)** —— 选下一步做什么的唯一标尺。
4. 动手前按上方 Pre-Development Checklist 走一遍。

> 上下文压缩后的恢复动作 = 读队列快照 + 读权限卡 + 续队首，**不请示**。禁止压缩后「重新发明项目世界」。

## Quality Check

- 权限卡四类**穷尽**：任何事项都能落进 自决直行 / 必问 / 禁停 / 灰区 之一；落不进 = 权限卡缺陷，登记 [issues](../issues/index.md)，不是停轮理由。
- 「必问」的正确处置 = **登记 + 保守默认 + 续推**。产出里出现「等待裁决 / 请确认后再继续 / 建议暂停」= **违例**，无论措辞多客气。
- 任何裁决请求里出现「暂停 / 等你审视」作为选项 = 违例。
- 每份简报第一节 = 队列快照，七行齐全、占位不留空。缺行 = 简报不合格（[队列与简报](./队列与简报.md#四简报快照格式)）。
- 一份规则只有一个住址。本层出现别层条文的副本（哪怕逐字正确）= 缺陷，合并留一 + 链接。
- 本层不写现值：出现写死的当前数字（格数 / 版本 / 节点清单）= 缺陷，改写成指针（[GOV-1]）。
- 跨文件引用只用**相对链接 + 标题锚**或**条目编号**（`ISSUE-NNN` / `[GOV-N]` / `[K-N]` / `I2`）。**引用行号 = 缺陷**——被引文件一改行号就腐坏成假引文。
- 完结任务不留在 active 列表冒充在飞。
