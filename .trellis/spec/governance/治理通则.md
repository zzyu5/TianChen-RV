## 六、治理通则

| 编号 | 规则 |
|---|---|
| **[GOV-1]** | **单一权威**：spec = 规范源；现状与数字住报告 + 主表（带锚点）；写作口径住研究档。**规范源本体不写现值**——条文见 [canon](../canon/index.md) §三.9，本层不重抄。治理侧效力：spec 里写死一个当前数字 = 缺陷，改写成指针。 |
| **[GOV-2]** | **任务口径统一**：任务状态必须从子项自动聚合或按固定节拍人工核对——「母任务待审核、子任务已完成」类张力应被脚本消灭。〔现行 = 保守默认：**按固定节拍人工核对**（每次简报的队列快照即核对点，见 [队列与简报 §四](./队列与简报.md#四简报快照格式)），**不新增脚本、不改 `task.py`**。无脚本保障一事的待裁项在 [issues](../issues/index.md)。〕 |
| **[GOV-3]** | **快照纪律**：条文见 [canon](../canon/index.md) §三.9（[G-1]/[G-3]），本层不重抄。治理侧效力：简报快照（[队列与简报 §四](./队列与简报.md#四简报快照格式)）与裁决请求是其载体——**无快照 ID 的数字不得进简报、不得作裁决输入**。 |
| **[GOV-4]** | **队列工件化**：队列为常驻工件（北极星 / 当前坐标 / 在飞 / 排队顺序即优先级 / 对账清单 / 测量欠账表），载体 = Trellis task 树（[队列与简报 §一](./队列与简报.md#一队列权威制)）；简报格式见 [队列与简报 §四](./队列与简报.md#四简报快照格式)。 |
| **[GOV-5]** | **决策权限卡**：见 [决策权限卡 §一](./决策权限卡.md#一权限卡)。 |
| **[GOV-6]** | **禁停机制**：见 [决策权限卡 §1.3](./决策权限卡.md#13-禁停机制)。 |
| **[GOV-7]** | **并行默认与工程债定位**：见 [队列与简报 §三](./队列与简报.md#三并行纪律-gov-7)。 |
| **[GOV-8]** | **代码事实优先于计划文档**：排期与立项前必须做代码事实核查；**计划文档陈旧不作为依据**。 |
| **[GOV-9]** | **命名冻结**：不得为既有概念自造新名；新概念先提案入 canon 再使用；**同名异义**（工具名 vs canon 概念）须在索引中显式消歧。 |

## 七、断言纪律（治理侧效力）

条文本体见 [canon](../canon/index.md)：缺席断言的核法 = §五.7（「X 不存在」类断言禁用有界窗口命令作依据；展示可截断，判断不许）· 转抄禁令 = §四.19（人工转抄数字非法）。**本层不重抄**，只定治理侧效力：

- 违反上述任一条产出的结论 = **作废，重做**——无论它已进了简报、任务交付物还是裁决请求。
- 依据作废的结论所做的**队列动作一并回滚**（登记条目改回原状态，**不留既成事实**）。
- 拿不准 → **不写数字**，写「见主表 + run-id」。
