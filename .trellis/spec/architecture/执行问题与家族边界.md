# 执行问题、Family Binding 与 Artifact 边界

本文是 V2 canonical execution problem、construction family 作用域及 artifact-neutral
边界的稳定正本。公式/selector 数学语义仍以 [变体流水线](./变体流水线.md) 为唯一正本；
本文只定义该公式之前和之后的 compiler 工位，绝不建立第二套公式。

## 【定法】系统边界

Weft 是 post-graph、pre-schedule 的自动 operator-to-kernel compiler：上游已经完成图级
融合、算子识别及必要 shape/layout 传播，Weft 接收语义充分、但尚未决定 family execution
mapping 的 operator problem。

这里 `pre-schedule` 只约束 source problem；family construction 本身负责产生 LMUL、tile、
warp、pipeline 等 execution schedule，artifact lowerer 不再选择这些决定。

```text
graph/model compiler
  → canonical operator problem
  → target/family binding
  → family-local construction
  → final typed execution body
  → family artifact/runtime
```

低层 RVV/IME/Scalar/future-GPU body 是 Weft 构造出的内部 execution IR；它可以作为
backend unit test/debug 输入，但不能代替 canonical source-to-body 路径来证明自动编译。

Weft 不接管完整模型图，也不新增通用高层 tensor/tile IR。多个 source adapter 可以接入，
但 adapter 不得决定 LMUL、tile、warp、pipeline、MMA、winner 或 artifact route。

## 【定法】Canonical Execution Problem

\[
P=(S,g,\omega)
\]

- `S`（operator semantics）：数学/离散计算、operand roles 与结果语义；
- `g`（typed representation facts）：format、encoding、packing、layout、shape/geometry 及
  与数据表示相关的事实；
- `ω`（bounded static context）：真实承重的 regime、必要 shape bucket、memory form 与
  静态 policy。

分型纪律：

- `S` 不携带 target schedule；
- `g` 不携带 capability、measurement winner、完整 point leaf id 或 artifact 名；
- `ω` 不包含 runtime data distribution、任意 context bag 或 winner memory；
- family-local formula 可以把上述事实规范化为自己的 typed input，但不能靠字符串、route
  metadata 或 emitter state 恢复缺失语义。

`S` 补足外部 compiler 问题边界，不改变主公式。进入某个具名 operator formula 时，`S`
已经由 source op 与 formula domain 固定，内部继续使用既有 `g/c/ω` 构造式。

## 【定法】Target/Family Binding

令 `t` 为显式 target/profile request：

\[
\operatorname{Bind}(P,t)=(f,c_f)
\]

- `f` 是 construction family，不是 artifact format；
- `c_f` 是 family-owned typed capability projection；
- binding 依据 typed target/profile、capability relation 与 family applicability；
- binding 不产生 candidate、不读取 measurement、不选择逐点 leaf；
- missing、ambiguous、conflicting 或 unsupported binding 一律 fail closed。

`Weft-RV` 与未来 `Weft-GPU` 是 realization 分组，不是 formula candidate。实际 family
可以是 RVV、IME、Scalar、未来 NVIDIA-GPU 或 AMD-GPU。H100/5090D 属于同一
NVIDIA-GPU family 的不同 capability profile，而非两个复制的 compiler。

当前 static/AOT 主链先绑定 family，再在该 family 内 construct/legalize/select。本文不定义
CPU/GPU 跨设备 runtime selector；未来若引入，必须另有 transfer、observer、artifact
共存、dispatch cost 与真实 workload 证据。

## 【定法】Family-Scoped Construction

绑定 `(f,c_f)` 后，既有主公式在 `f` 的作用域内原样成立。`f` 拥有自己的：

- typed problem projection；
- mechanisms 与 formula；
- candidate/plan 类型；
- legality/resource model；
- analytic prior 与可选 measurement key；
- final typed body；
- construction-strength classification。

跨 family 共享 construct → legality → bounded select → final body 的因果顺序，不共享一个
physical Plan、FormulaResult、mechanism AST 或 resource model。

Family binding 和 family 内 selector 是两个不同工位：前者建立知识作用域，后者只在该
作用域已经构造且合法的有限候选中选择。两者都不得推迟到 artifact lowering。

## 【定法】Construction Completion

construction completion 的判据是：family owner 已从 typed `P+c_f` 构造或严格资格化完整
final typed body/plan，且 legality/selection 所需结果已经消费，并返回 exact typed
operation/root。它不以任何特定 artifact dialect、`emitc.func`、C symbol、route id 或
metadata 为定义，也不允许公共层随后扫描 module 重新发现“真正的”body。

construction completion 仍不等于 strong reconstruction：依赖完整 point leaf 的结果只能
标为 `ConstructedWeak`；删除 point leaf 后能由 `g/c/ω + reusable mechanisms + formula`
重建同一 body/legal domain 才是 strong construction。

禁止建立 universal verifier/provider 来判定 construction。Family owner 产生 typed result，
通用编排只检查 owner 唯一、调用顺序和结果是否存在；IR verifier 只保护结构/类型/ABI，
不重放公式。

## 【定法】Artifact Contract

artifact lowering 只消费 construction-qualified final typed body：

```text
final typed body
  → family artifact driver
  → target dialect/toolchain handoff
  → object/device module/header/bundle
  → family ABI/runtime
```

artifact driver 可以是：

- 当前 RISC-V family 的 EmitC/C/C++/native-object 路径；
- future NVIDIA-GPU 的 GPU/NVGPU/NVVM/device-module 路径；
- future AMD-GPU 的 GPU/AMDGPU/ROCDL/device-module 路径。

公共 artifact orchestration 可以管理 identity、ownership、typed handoff、ABI/provenance 和
fail-closed，但不得解释 family compute。`emitc.func` 是 EmitC artifact backend 的完成门，
不是全系统 construction 或 artifact 的通用完成门。

原主公式中的 `Emit_v(c)` 不因此被替换：它仍是 family 构造式内把已确定 mechanisms 与
parameters 机械组成候选实现的投影。最终 object/cubin/hsaco packaging 是其后的
`LowerArtifact_f`，不能获得第二 compute authority。

## 【定法】Source、Construction 与 Artifact 的唯一 authority

| 对象 | 唯一 owner | 禁止 |
|---|---|---|
| operator semantics `S` | source problem op/adapter | family emitter 从名字猜 operator |
| representation `g` | typed source/format owner | capability、winner 或 point leaf id |
| context `ω` | bounded static context owner | runtime distribution、任意 bag |
| capability `c_f` | family capability projection | giant cross-family optional struct |
| mechanisms/formula | family construction owner | common provider 或 emitter replay |
| final body/plan | family typed execution IR | metadata/route id 替代 |
| artifact/runtime | family artifact driver | 重新选择 mechanism/tile/LMUL/warp |

## 【现状】2026-07-23 实现基础与缺口

已经成立：

- current production authority 已横向进入 artifact-neutral
  construction-before-artifact；
- quantize/dequantize 复用 RVV top-level construction cut；
- RVV `flat_*` final computation plan 由 formula 产生，emitter 直接消费；
- target/profile 在 construction 前绑定 origin family 与 typed `c_f`；
- RVV、IME、Scalar、Demo、Toy、Template 与 TensorExtLite 都显式实现
  `constructFormulaPlans(FamilyConstructionRequest, FamilyConstructionResult)` 并返回 exact
  typed result，base construction fail closed；
- `TypedBackendEmissionDriver` 不再含 construction hook；
  `convertConstructedModuleWithBackendEmitter` 与
  `tryConvertConstructedModuleWithRegisteredBackend` 只做 constructed body 的 artifact
  projection；
- `emitc.func` 只作为 current EmitC artifact 的完整 legalization gate。

当前 A/B 横向任务已经完成的第一项清理：

- Demo、Toy、Template 与 TensorExtLite 不再维护 construction manifest、typed-role graph、
  route provider、通用 readiness verifier 或 role/status/interface 字符串镜像；
- metadata-only `lowering_boundary` 已删除，family construction 直接返回 typed compute
  body/root；
- common readiness/plan 直接接收该 exact result，只检查 ownership/existence；
- family contract 中的 artifact route/ABI/callee 是 body 之后的机械常量，不参与 legality、
  candidate、completion 或 compute。

仍需继续收敛但不回退上述边界：

- source/problem `S/g/ω` ownership 已可由 source/formula catalog 枚举，但物理事实仍分散在
  loose op、front door 与 family attrs；后续只在真实 code-affecting 数据流上继续集中；
- 已闭合的 construction-before-artifact caller 与负例必须持续保护；
- Scalar 等路径仍需检查 formula 是否只产生参数字典、而完整算法仍藏在 artifact leaf；
- `ConstructedWeak` leaf 仍需多 topology delete-leaf reconstruction 才能升级 strong
  construction；
- 重构后 current artifact 的 correctness、deployed、strong-opponent 与 e2e 性能必须由 B 线
  重新给出 paired evidence。

这些剩余工作不是 GPU 已实现缺口的另一种说法，也不授权恢复 backend-side
construction。

## 【定法】已落地的 GPU 前置横向重构契约

本轮 project-wide cutover 建立并必须继续保持：

1. 固定 source/problem entry 的 `S/g/ω` contract；
2. 建立 artifact-neutral target/family binding；
3. 让每个 live family 的 construction lifecycle 归 plugin/family typed owner；
4. 删除默认成功 construction 与 EmitC driver 内的第二 construction authority；
5. 让 EmitC driver 只消费 construction-qualified final body；
6. 让所有 source/direct/pass/translate/artifact caller 经同一 construction seam；
7. 将 `emitc.func` 完成门留在 EmitC artifact backend；
8. 保持旧路径原子退役、无 compatibility middle path。

本 cutover 横向覆盖 RVV、IME、Scalar、Demo、Toy、Template、TensorExtLite 与 Offload
explicit unsupported；不创建 GPU dialect、GPU plan、GPU runtime 或 GPU 测量。

## 【定法】禁止结构

- GPU 作为 current EmitC registry 的新 emitter；
- RVV body/`flat_*` plan 转译成 GPU compute；
- family 只在 emission 时才确定；
- source descriptor 携带完整 backend schedule/template；
- universal capability/Plan/FormulaResult/provider/verifier；
- artifact lowerer 从 `kind/format/fold_model`、device 名或 metadata 重选；
- current architecture target 被写成 GPU 已支持事实；
- 为迁移保留旧 direct emitter、compat adapter 或双 construction hook。

## Tests Required

- 每个 production source entry 的 `S/g/ω` ownership 与唯一 construction owner；
- target/family binding missing/ambiguous/conflict/unsupported 负例；
- 每个 live family 的 artifact-neutral construction 正负路径；
- construction completion 不依赖 EmitC 类型的静态/接口测试；
- current EmitC artifact 仍要求完整 legalization 与 `emitc.func`；
- direct/pass/translate/artifact 调用同一 construction seam；
- mixed/unowned/unconstructed body fail closed；
- quant/dequant 对称与 RVV `flat_*` no-redecision 回归；
- full catalog/registry 与完整 `check-weft`。
