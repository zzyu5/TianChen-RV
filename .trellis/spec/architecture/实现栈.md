## 【定法】Primary Stack

Weft-RV MLIR 是一个**真实的 MLIR 编译器项目**。主实现栈：

```text
C++
MLIR
LLVM
TableGen / ODS
CMake
lit / FileCheck
```

该栈对以下各项**强制**：

- core IR 与 dialect 实现；
- `weft.exec` operation 定义与 verifier；
- WEFT extension family（RVV、IME、TensorExt、Offload 及未来 vendor/custom 家族）；
- compiler pass；
- plugin registry 与 interface；
- capability model 的编译器对象；
- variant 生成、legality、selection、dispatch、lowering、emission；
- MLIR parser/printer/verification 行为；
- build 集成与测试。

## 【定法】Python Boundary

Python **仅允许**用于 tooling：

```text
runner
supervisor
remote probe
artifact parsing
report generation
small support scripts
developer convenience wrappers
```

Python **禁止**作为以下各项的实现语言：

```text
core IR
dialects
passes
plugin registry
capability model
variant pipeline
lowering pipeline
emission pipeline
compiler legality model
compiler decision objects
selected-body realization
plugin route authority
capability mapping
typed extension-body generation
```

## Wrong vs Correct

Wrong:

```text
Implement `weft.exec.variant` as a Python class and run legality with Python dictionaries.
Represent capabilities as JSON-only objects consumed by Python pass simulators.
Use Python to lower pseudo-IR into strings and call that the compiler pipeline.
```

Correct:

```text
Define dialect ops in TableGen / ODS.
Implement verifiers, passes, registries, and lowering in C++ using MLIR/LLVM APIs.
Use Python only to run `mlir-opt`, launch board probes, parse artifacts, or supervise runs.
```

对 RVV：Python **不得**生成权威的 typed `weft_rvv` body、决定 dtype/config/operation 事实、realize selected body、映射 RVV intrinsic、构造 route provider payload、或实现 capability 关系。Python **只**可在 compiler-owned 的 C++/MLIR 路径仍是真值来源的前提下准备 fixture 或 probe。

## 【定法】Missing Toolchain Rule

若本地 MLIR 工具不可用：

- 为所需工具（`mlir-opt`、`mlir-translate`、`FileCheck`、`llvm-lit`、`clang`、`cmake`）加检测；
- 发清晰诊断，把 MLIR 行为测试标为 blocked 或 unavailable；
- **不得**为了继续推进而用 Python 结构替代 MLIR 编译器内部（fail-closed，见 I6/I7）。

## 【定法】Build Integration

编译器组件必须可经 **CMake** 构建。新的编译器库、dialect、pass、tool 与 test 从一开始就应有 CMake 归属，哪怕第一个切片很小。

## 【定法】Test Integration

MLIR 语法、解析、验证、pass 行为与诊断应经 **lit / FileCheck** 验证。**C++ 单测**适用于 registry API、capability model helper 与非文本的编译器工具。
