# 退役与单一生产路径

本文只规定 active compiler path 的 authority 切换和兼容边界。它不是迁移流程、审批
表或 task 模板。规范性摘要见 [canon · 核心不变量](../canon/核心不变量.md) I7。

> **[RET-1] Evolvable operator compiler, not compatibility museum**：Weft 是可扩展的
> MLIR operator compiler / execution-layer software stack，不为错误的内部 API、旧
> pass pipeline、实验 dispatcher 或历史 fixture 长期保留生产兼容层。RISC-V 量化推理
> 是当前旗舰实现，不是系统类别或兼容边界。

## 【定法】唯一的是 compute authority

同一输入域可以有多个合法 candidate，也可以有分层但职责不同的 orchestration；禁止的
是两个部件同时决定同一 computation。一个稳定生产路径应具有：

```text
typed facts/capability/context
  → one family-local formula/construction authority
  → legality
  → optional bounded selector
  → one final typed body
  → one mechanical realization/emission path
```

以下形态必须退出 active path：

- 同一决定的新旧 provider/helper/reader/writer/selector/dispatcher 并存；
- selected stamp 缺失、construction 失败或 emitter 失败后转回旧实现；
- `compat`、`legacy`、`deprecated` alias 或 old↔new adapter 继续承载 compute；
- emitter、route provider 或 verifier 根据 format、board、model、reason、provenance 或
  measurement 重新构造 candidate/plan/body；
- code-affecting 字段用 `value_or`、环境开关或字符串身份恢复历史默认；
- 已无真实 caller、合法实验职责或负对照职责的 dormant strategy、gate 和 fixture。

旧代码是否仍有 caller、是否曾经获胜、名字是否叫 monolith，都不能单独决定去留。判断
标准是它是否表达不可替代的现行语义，还是与新 owner 重叠。

## [RET-F] 横向 formula/construction 切换

建立共享 formula/construction layer 时，迁移单位是当前代码可达的完整生产域，而不是
五个 dequant 公式、一个 operator 或一个 backend 的纵向样板：

```text
registered/direct production entries
+ production analytic/construction owners and callers
+ declared decisive g/c/ω dependencies
+ superseded provider/replay/emitter authorities
```

实现过程中可以按文件施工，但最终合入必须同时满足：

- 全部当前 production entry 进入 catalogued family-local construction；
- deterministic path 也显式构造 final typed body，不以“没有选择”为由绕过；
- 与公式同义的旧 caller、compatibility bridge、planner/verifier replay 和
  emitter-side decision 已删除；
- 测试直接保护公式结果的因果作用、真实入口和机械消费。

无法闭合完整生产域时，改动仍是未完成 worktree，不能把“其余以后迁”包装成已完成的
架构状态。这个原子性只要求 authority 一次切换，不要求同一提交已经把所有
`ConstructedWeak` leaf 变成 strong construction；两者必须分开陈述。

## 【定法】final typed body，不是 stamp 生命周期

Formula/construction 一次产生完整 candidate/plan；selector 如存在，只返回完整合法
candidate；随后直接构造 final typed body。生产设计中没有：

```text
none → partial → selected → stamped → verified → materialized
```

也没有事后遍历 IR 补字段、由 verifier 回放公式、或 reader 在 emission 附近再次拼出
计划。Verifier 可以检查 IR 结构、类型、闭集、parent/child 一致性、ABI/ISA 和资源安全
不变量；它不能定义、补写或纠正 compute。

## 【定法】语义 fallback 与兼容 fallback

| 类别 | 判据 | 处置 |
|---|---|---|
| 语义 fallback | 本来就是公式构造出的具名合法 candidate/body，并经过相同 legality 与正确性约束 | 保留并测试 |
| Reject | 当前输入没有合法实现 | emission 前 fail closed，并给出 bounded 诊断 |
| 兼容 fallback | 新链缺字段、失败或未接完，于是调用旧实现或猜历史默认 | 删除；存在即 authority 未收敛 |

旧 scalar/generic body 可以作为正式语义 candidate；它不能只在新 construction 失败后被
旁路调用。测试专用 oracle 和历史 baseline 必须与 production registry/default route 隔离。

## 【定法】修改与验证

不要求为普通重构填写 cutover record、predicate 表、ledger 或固定验证矩阵。与风险相称
地直接检查：

- 旧 production symbol/caller/registry row 已不可达或物理删除；
- 真实 source/direct entry 只经过一个 construction owner；
- decisive `g/c/ω` 变化能改变 typed result、legal set 或 emitted code；
- missing/unknown/illegal 输入 fail closed，不回旧路；
- 既有 byte-exact/ULP、ABI、bundle 和 plugin 行为未被破坏；
- 性能主张仍由真硬件 measurement 独立证明。

Grep、catalog 数量和 task 状态只能帮助定位，不能代替行为测试。修改 emitter/verifier 或
共享 IR layout 时，按 [governance · 思维准则](../governance/思维准则.md) 的构建事实选择
强制重链或 clean rebuild。

## 正反例

正确：

```text
formula constructs complete candidate/plan
  → legality / optional selector
  → final typed body
  → mechanical emitter
old authority and compatibility caller = 0
```

错误：

```text
new formula handles several entries
  → adapter or missing-stamp fallback
  → old provider/emitter handles the rest
```

错误路径即使被标为 deprecated、默认关闭或 future，也仍是双 authority。
