## 3.0 哲学与稳定性条款

**哲学一句话：不可变 run 是测量事实，qualified recon publication 是正式主表事实；采集者不得自行升格。**

一次板端动作先产生唯一 `run-id`、原始工件与 run event。它可以诚实地处于 `measured but unqualified`，但此时不能成为正式引用数字或 selector winner。只有 correctness、lineage、freshness 与 T-N 门齐全后，qualification view 才能把该 run 标为 master input；`recon_master_rebuild.py` 是 T3 master 与 rowclue 的唯一 publisher。`selection_valid_input` 另要求合法候选内的成对比较，不由 master qualification 自动推出。

**稳定性条款**（作用：使判据在战役全程恒定，杜绝中途改判与结论反转）：

1. 本层版本化；**修改的唯一途径 = 用户裁决**。
2. 执行中发现的新问题一律进 [ISSUES](../issues/index.md)。
3. **禁止热改流水线、禁止临时加门、禁止战役中途换判据。**
4. agent 可以提案，不可以自改。

## 3.2 单一目的地法

（作用：杜绝"跑一次测量、长出一堆新文件与新叙事"。）

1. 持久数据仍固定在三处，但 writer ownership 分立且不可互换：

   > **【已建·现役】**：`experiments/master/`（recon-only T3 canonical view + rowclue + 板源 CSV）· `experiments/runs/<run-id>/`（bench 不可变原始工件）· `experiments/runs.log`（bench append-only 台账）。旧 `experiments/active/result-tables/` 不是 fallback reader 路径。

   - `experiments/master/`：T3 主表、板源 CSV 与 rowclue —— **唯一正式主表住址；只有 recon 可发布**；
   - `experiments/runs/<run-id>/`：该次运行的原始产物与 `row.csv`，创建后不可被同 run-id 覆盖；
   - `experiments/runs.log`：append-only 运行台账，每次调用一行 `{run-id·时间·格·结果|VOID 原因}`。

2. bench 禁止写目的地以外文件，也禁止写 `experiments/master/`。VOID 只留台账；成功采集留 immutable run + 台账。qualification/cache view 是控制面生成物，不是第四份结果账本；数字仍必须可回溯到 run/master。

3. 报告引用数字 = **引用行字段 + run-id**。**人工转抄数字非法**；工具能输出的数字禁止手算重述。

4. **★住址（代码）与落点（数据）是两件事**（2026-07-17 用户裁）：

   - **测量的可执行物住 `tools/`** —— runner（现址 `tools/bench/bench`）与每格对拍/计时 harness 一律**在 `tools/` 之下**。理由**不在本层发明**：`experiments/` 是**数据格**，`tools/gates/check_experiments_layout.py` 对脚本 / `+x` / `^run_` 命名入内**逐条判 RED**（该门自述「harness lives under tools/, never in the data cell」）。**该门的判据本身不动。**
   - **bench 写入只落 runs 与 runs.log；recon 独占 master** —— **`tools/` 下不落数据格**。runner 写入闸必须把 master、旧址和散件都作为负控咬住。
   - ⟹ **住 `tools/`、写 `experiments/`。** 「harness 不许住数据格」与「数据不许住 `tools/`」是**同一条法的两面**，不得援引任一面去推翻另一面。

   > **★选址与契约【已裁】**（[ISSUE-090]）：每格/每族 harness 住 **`tools/bench/cells/`**；e2e harness 住 **`tools/e2e-harness/`**。harness 由 `bench` 按声明接口调用且自身禁写文件；bench 只封存 run，正式升格走 qualification → recon。
