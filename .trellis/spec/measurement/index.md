本层是本项目**一切测量活动的唯一法源**：什么算测量、在哪块板测、用哪条流水线测、跟谁比、结果写到哪、哪些检查作数。凡涉及"跑出数字"的动作以本层为准；**本层未授权的测量动作即非法动作**。

测量之外的领域见各自的 layer，本层不重抄：已定法条合订见 [canon](../canon/index.md)，架构定法见 [architecture](../architecture/index.md)，证据地图见 [evidence](../evidence/index.md)，队列治理见 [governance](../governance/index.md)，问题登记见 [ISSUES](../issues/index.md)。

**本层的修改途径 = 用户裁决**（细则见 [3.0 哲学与稳定性条款](./哲学与目的地.md#30-哲学与稳定性条款)）。agent 可以提案，不可以自改。

- [ ] 写入目的地是否只有[单一目的地法](./哲学与目的地.md#32-单一目的地法)许可的那几处？有没有新开报告 / 新开表 / 新开目录？
- [ ] 走的是唯一合法测量动作 `bench <格> --board <板>` 吗？（runner 现状见 [3.3](./流水线与行schema.md#33-一条流水线)——**已建于 `tools/bench/bench`**；**干跑路径可用**，**真实测量路径仍阻塞**于 [ISSUE-090](../issues/门与工具.md#issue-090--每格对拍计时-harness-的住址与契约未定义33-第-34-步无可寻址被调物) / [ISSUE-091](../issues/门与工具.md#issue-091--bench-格-单独不定位主表行行键不在-331-字段表内--与现役表结构无映射) / [ISSUE-073](../issues/index.md)，总账 [ISSUE-067](../issues/index.md)）
- [ ] 三个硬点（**静板预飞 · 对拍 · 世系**）是否全部自动执行并自动留痕？（[3.5](./门体系.md#35-门体系清算三硬点其余皆工具)）
- [ ] 对手是**该板 ggml 实际部署派发的函数**吗？以**部署事实**证成，不是以可得性证成（[3.4](./对手法.md#34-对手法)）。
- [ ] 对手档位 `{手调 | 通用向量 | 标量类 | 域外 | N/A-hw}` 是否**逐格证据判定**、证据引用是否入行？
- [ ] 该对手**家族**做过一次性身份探针 + 故障注入对照吗？（按家族一次，不按格重复）
- [ ] 计时之前，正确性门过了吗？整数路径 byte-exact、浮点路径 ULP 上界（[正确性门](./正确性门.md)，[K-5]）。
- [ ] 重复数**预注册**了吗？预注册先于测量（[3.6](./流水线与行schema.md#36-其余铁律)）。
- [ ] 比值落在 **0.7–1.0**？落在即须追加一次独立复测确认并打噪声标（[3.3](./流水线与行schema.md#33-一条流水线) 近门补充）。
- [ ] 该板的板别约束读过了吗？（k1 禁性能计数器主张 · scalar 构建须显式关向量：[板册](./板册.md#37-板别注记)）
- [ ] 要新增一个检查？**唯一途径 = 提案入 ISSUES → 用户裁 → 本层版本化更新**（[3.5](./门体系.md#35-门体系清算三硬点其余皆工具) 第 4 条）。不存在其他途径。
- [ ] 报告里的数字是**引用行字段 + run-id** 吗？人工转抄数字非法。

## Quality Check

- 一次测量 = 主表一行发生一次受控更新 + 运行台账一行。**没有第三种持久产出。**
- VOID 的行不存在：VOID 只在运行台账留一行，不入主表。
- 验收**查世系不查字样**——编译器身份三元 `{板·链·批次}` 自动写入行。
- 对手数值错误 → 成绩**作废登记**，降落该板下一真实派发路径；**禁用坏对手时间算倍率**。
- 本层是**权威**，runner 是**实现**。任何"schema 以 runner 实现为准"的读法都非法。
- 板忙只延后**验证**，不延后**施工**——"constructed·待板端门"是合法状态。
- **"某物不存在"的断言禁用 `head` / 固定窗口命令作依据。**

## 术语

> 本节只解释本层用语，**不新增规则、不新增判据**。规则全部在 3.0–3.7 各条文文件。

- **格**：一个量化格式，`bench <格> --board <板>` 的格参数 = 行键的 **`format` 分量**。**格 + 板【不】定位一行**（此前本条写"与板组合定位主表的一行"= 已订正的事实错：一个格跨多 op·多 regime，且板不是键）。
- **行**：主表 T3 CSV 中的一条记录（主表现址与目标址见 [3.2](./哲学与目的地.md#32-单一目的地法)）；**行键 = `(op, format, engine, regime)` 四元组**，**权威字段集 = [3.3.1 行 schema](./流水线与行schema.md#331-行-schema规范性) 的字段表**（非 runner 实现）。
- **值域**：某字段的合法取值集合。登记值域 = **机算枚举**（[3.6](./流水线与行schema.md#36-其余铁律)）；`判定` 的值域住 [3.3.1.1](./流水线与行schema.md#3311-判定-的值域规范性--零预处理机算枚举)。
- **run-id**：一次 runner 调用的标识，同时作为该次运行原始产物目录的目录名与行内引用锚。
- **VOID**：运行作废——**不计时、不入行**，只在运行台账留一行含作废原因（脏板 / 我方错 / 对手废 / 派发不符）。
- **近门**：比值落在 **0.7–1.0** 区间的结果，触发一次独立复测确认。
- **世系**：编译器身份三元 `{板·链·批次}`，由流水线自动写入行；验收以世系为准，不以字样为准。
