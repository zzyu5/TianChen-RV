# 正确性门 — byte-exact 先于计时 + 浮点 ULP 上界（[K-5]）

> 本层入口与术语见 [index](./index.md)。本文件是 **[K-5] 正确性门的权威定义处**；其法条形态住 [canon · 正确性与证书](../canon/正确性与证书.md) [K-5]。**禁副本**。

**计时永远在正确性之后。** 正确性门是[流水线](./流水线与行schema.md#33-一条流水线)第 3 步（对拍）的判据形态；对拍任一侧失败 → **不计时**，落 VOID。

## 门的形态（[K-5]）

- **整数路径 byte-exact**：与结构无关 oracle 逐字节相等。
- **浮点路径 ULP 上界**：不追字节精确，改**声明 ULP 上界**并断言不越界（fp16 次正规 / 极端指数等极端输入进性质测试）。
- **oracle 结构无关（实验宪法 §1.8）**：标量 oracle **不与**任何向量参考共享 bit→lane 解码；配性质测试（全零 / 交替符号 / 满幅 / fp16 次正规）+ 变异测试；oracle 入库有版本。
- VLEN 翻转 lit 矩阵 ≥ `{128,256}×{m1,m2,m4}`，每板 objdump golden（指令形态 + LMUL 断言）—— 结构证明格，进 CI。

## 钉死的 oracle

平面块量化 `vec_dot` 家族（q8_0/q4_0/q4_1/q5_0/q5_1，后续 K-quant/码本同构）的**具体折叠规格**见 [浮点折叠 oracle](./浮点折叠oracle.md)——一次钉死，永不随变体重定义；**不对 ggml 二进制验收**。

- **beat 主张的放行通道** = [PERF-1] 门体，其门项与本门的关系见 [canon · 测量判据](../canon/测量判据.md) §一.2（本门 = 该门体第 ① 项）。本门只管**正确性**，不放行任何 beat 措辞。**引用该门一律用 `[PERF-1]`、禁带门数**（`ISSUE-071` 已裁：门体 = 十项，**门数只住该定义处**）。
- **证据格 schema 与状态枚举** `{measured|stale|board-pending|open|n_a}` 与 **T-N 噪声地板**的权威声明住 [canon · 测量判据](../canon/测量判据.md)（§二.7 / §二.5）；**对手类词表**（角色）住 [canon · 对手与档位](../canon/对手与档位.md) §一。本层的[对手法](./对手法.md#34-对手法)规定其在流水线中的取证与落账方式，**不重定义词表**。
