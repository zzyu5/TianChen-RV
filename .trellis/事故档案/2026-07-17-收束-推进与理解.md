## 五、两个真发现（这两条是硬的，值得留）

### 5.1 dequant 发射器零向量发射 = 族级缺口（PR-31）

```bash
for f in experiments/active/g8-stage3-attack/A2-batch8-k1-dequant-raw/kernels_dequant/*.dq.c; do
  grep -oE '__riscv_v[a-z0-9_]+' "$f" | wc -l; done      # 全 18 格恒 = 2
```

全 18 格 dequant 核的向量 intrinsic **恒 = 2，且两条全是 `vsetvl`** ⟹ **真向量运算 = 0**。源码实证（`q4_K.dq.c:7`）：`size_t v4 = __riscv_vsetvl_e32m1(v1);` —— **`v4` 此后再未被引用（死值）**，其后全是 plain C。

⟹ 我方 dequant 核的**全部向量内容 = 宿主编译器 autovec 的产物**，emitter **零控制权** ⟹ **dequant 轴输赢 = codegen 抽签**。铁证：同一字节源 `iq1_m` 在 gcc-15.2 下 `AVrvv=0`、clang-20 下 `AVrvv=256`。

**量级 = 主表 24/108 行 · 36 board-cells。** 标量类 24 个非 PASS 的绝大多数由它解释。

### 5.2 「recon 输出零 gcc·grep=0」是空心门（PR-47 待写）

**变异测试（我自己复跑）**：

```
对照 A（现状）：            grep = 0/0/0   master sha256 = 1a50018c7ce104c3
```

**机制**：recon 的注记全是脚本内**硬编码字面量**，从板 CSV 只取 **token 分类**（f[35]）与**数字**（f[29]）——**文本不透传** ⟹ gcc 字样**结构上不可能**出现在输出。

## 七、★停机自身留下的一个活陷阱（必须交代 · 我造的）

写 §七 时我本想写「零改动·git status 可证」——**按字面是假的**，当场自查揪出下面这件事。

**事实链（每步机验）**：

```bash
git stash list | head -1
# stash@{0}: WIP on full-refactor-m1: 4413ba6b9 ...

```

**判决性实验**（排除「名字从输入穿过来」这个平凡解释）：把输入 MLIR 里该名**全部改成 `ZZZ_PROBE_NAME`** 后重跑 → emit 里 `sum2_half_lane_mask` **仍 = 1**、探针名 **= 0** ⟹ **名字烧在 binary 里，不来自输入**。定位到 `libWeftConversionRVV.a`(09:36) 的成员 `RVVToEmitCTernaryBinary.cpp.o`。

**成因（时间戳自洽）**：`.a`/`weft-opt` 建于 **09:36**（当时源码含 sum2 batching）→ **09:41** 我 TaskStop `wdsux5xlt`，改动被 **stash**，源码回退到 HEAD（mtime 09:41 > 09:36）→ **binary 保留了 stash 版发射器**。

**危害 = 绿在幽灵上**：那 2 个未入库 test（`...grid-core-scaffold.mlir` / `...export-e2e.mlir`，+54/−11）**已经改成期望 batched 形态**（含 `NOTINY` 反回归 pin）。**现在用树里的 binary 跑 lit → 绿**；**clean rebuild → 立刻红**。绿的是一个**源码里不存在**的发射器。

> **订正我自己**：我一度准备把这个报成「binary 含源码里不存在的代码=污染大发现」。**错**——代码**没丢**，在 `stash@{0}` 里，是我停机动作的正常产物。**真正的问题不是代码丢了，是 binary 与源码脱钩、而 test 站在 binary 那一边。**

**这是 `[[build-incremental-unreliable]]` 的恶性变种**：旧记忆讲的是「binary 少了新代码（→红，会被发现）」；这次是「**binary 多了已撤代码 + test 配合它（→绿，不会被发现）**」。

**处置（留给用户裁 · 我不自决）**：`stash@{0}` 是 P3-Q1B 唯一载体，**丢弃 = 不可逆** ⟹ 属硬冻结邻域。我**原样保留**，只登记。**下一会话第一动作必须是 forced rebuild**，否则任何 lit/测量都在测幽灵。
