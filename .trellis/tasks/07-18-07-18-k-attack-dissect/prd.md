# PRD · K线 · 两档非PASS格攻坚环 · 解剖阶段

> **权威** = 《开测篇》§二.3「每非 PASS 格走完整攻坚环（解剖→构造→前门→板上对拍→cold）·确经完整攻坚环仍架构不可达者置顶具名上报·零静默认输·零未攻认输」。
> **本 task = 解剖阶段**（诊断·案头·只读）。服务停止条件① 两档全表 PASS ≥0.8 收口。

## 一、输入（机算·31 非 PASS 格）

- **标量类 22 格** · **通用向量 9 格**（含重复格·去重后按 op-family）。

## 二、★分流（先分两类·解剖法不同）

- **(A) 具名-X ~20 格**（部署对手·真输）→ **本 task 解剖**：逐指令墙分类。
  例：iq1_s/iq1_m/iq3_xxs/iq3_s/iq4_xs @rvv,k1 · q4_K/q5_K/nvfp4/tq2_0 @rvv · offset_binary_n3@k1。
- **(B) pending/pending-fold ~11 格**（iq2_xs/q4_1/q8_0/iq4_nl 等·未测/未落账）→ **不属攻坚**，
  归 **harness 基建 / 落账队列**（gated on bench harness·ISSUE-099）。本 task 只登记归属，不解剖。

## 三、解剖产出（每个 (A) 格）

`objdump` 逐指令认瓶颈 + **三档墙分类**：

| 墙类型 | 含义 | 裁定 |
|---|---|---|
| **可攻坚旋钮** | 有明确机制能翻 ≥0.8（如 VLEN 专化 leaf·tiny-reduction 向量化） | **攻坚候选** → 登扇出台账（机制 + 命中格 + XFER 预测） |
| **我方指令数内禀墙** | 我方 generic aux32 未专化·指令数天然多（vsetvl spill 等） | 若无旋钮 → **架构不可达**（具名上报·带逐指令墙证据） |
| **对手结构优势** | 对手 VLEN 专化 full-unroll hand-brick·结构性快 | 同上·非静默认输 |

## 四、★复用前役墙证据（禁重复劳动）

- **iq1_s/iq1_m/iq3 系** P2 已解剖：对手 VLEN 专化 full-unroll ~150–314 ins vs 我方 generic aux32 ~13k–21k ins。
  **直接引用·不重挖**；只对**未解剖的新格**（q4_K/q5_K/nvfp4/tq2_0/offset_binary_n3 等）深挖。
- **iq3_s 板间翻转**（rvv 1.34 赢 / k1 0.61 输·同 leaf）= **VLEN 专化满展开 leaf** 的活证 → 该机制列扇出台账首条。

## 五、验收标准

1. **20 个 (A) 格逐格**：{瓶颈（objdump 证据）· 墙类型 · 裁定（攻坚候选/架构不可达）}。
2. **攻坚候选** → 按机制聚类成**扇出台账**（机制 → 命中格 → XFER 正/负预测）。令文 §二.4 手调按机制列队。
3. **架构不可达** → 置顶具名上报（**完整攻坚环证实**·带逐指令墙证据·**非未攻认输**）。
4. **(B) 11 格** → 登记归属（harness/落账队列），不解剖。
5. **0 造数**：墙证据带 objdump；架构不可达须真解剖证实，禁降标偷过。
6. **触碰集**：只读 `lib/` + 反汇编（`ssh rvv/k1` objdump）。**不改代码·不测量·不 commit**（产诊断报告）。
