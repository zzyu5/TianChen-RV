# perf-covered 零未定义格逐格判读(84 格分类·随接线线)

parent: `07-11-G5-wiring`（G5 接线战役）· status: **planning** · 域: **判读/账本**。

用户 2026-07-12 裁。perf-covered 终态 = **零未定义格**——84 格每格必须落进声明制状态，禁「未定义」。本任务随接线线（q6_K/K-quant 等）推进逐格判读，非一次性大盘扫描。

## 每格判读协议
1. **过 X-0**：对手身份/八门状态/账本(kernel vs system)/双方编译器身份/板 shipped-baseline 编译器 全绑（性能主张七要件）。
2. **过 Amdahl 传导预估**：目标占相内时间比例 × 预期改善 = e2e 上限；上限低于噪声地板 → 只能机制/方法学名义，不得 perf 名义。
3. **分类落格**：
   - **green**：full-stack 无星号绿格（公平协议 ≥ parity / 赢·登记 perf-covered）。
   - **yellow（带账）**：对手 SELF / e2e 门开 / 编译器不对称 等 → 绿格带账（明写欠账项）。
   - **域外**：[G-2] 等域外名单（bf16/flash_attn 等·声明例外）。

## 目标
- **零未定义格**：84 格 ∪ = {certified/green} ∪ {yellow-带账} ∪ {域外声明例外}，无未定义残格。
- 随接线线增量推进（q6_K 落地 → 判该格；后续格随各线落地逐格判）。

## 判据
- 每格判读绑七要件 + Amdahl，禁投影直觉（[GAP-P1] widen/re-roll 两次证伪为戒）。
- recon 脚本强制声明制：任何格状态缺失即 RED。
